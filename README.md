# 回声岛 Echo Island

给初一（七年级）学生的英语**听说**闯关游戏。纯网页，不用安装、不用服务器，打开 `index.html` 就能玩。

## 怎么玩

- **13 座小岛**，每座岛对应七年级的一个常见话题：问候、文具颜色、家庭、学校、学科、社团、作息、生日、动物、规则、运动饮食、天气、过去的经历。
- 每座岛 **7 关**，从易到难：听词 → 说词 → 听句 → 说句 → 对话 → 综合挑战 → **Boss 对话战**。打败 Boss 解锁下一座岛。
- 题目每次随机生成，重玩不会一模一样。

| 听力题 | 口语题 |
| --- | --- |
| 听音选义、听音选词、听句选意、听问选答、听音排句 | 单词跟读、句子跟读、看图说英语、说出回答、Boss 对话攻击 |

## 让孩子想继续玩的设计

- **连击**：连续答对 3 / 5 / 10 题，经验 ×1.5 / ×2 / ×3，音效越来越高
- **星星**：不丢心、答对 90% 以上拿三星；首次三星额外奖励金币
- **等级和称号**：见习水手 → 听力侦探 → 口语新星 → …… → 传奇船长
- **连续打卡**：每天完成一关就算打卡；**连胜保护卡**可以自动补一天
- **每日任务 + 宝箱**：每天 3 个任务，做完开宝箱，可能开出商店里买不到的限定宠物
- **宠物店**：用金币买宠物，宠物会在地图上陪着闯关
- **幸运暴击**：通关时有 15% 概率金币翻倍
- **19 个成就**、**错题本**（答错的题自动收集，复习答对就移除）
- **3 颗心 + 复活**：心用完可以花金币复活一次

也有照顾孩子的设计：连续玩 30 分钟会弹出 20 秒的**护眼休息**；口语题说不好**不扣心**，最多试 3 次后自动放进错题本。

## 口语打分

- 浏览器支持语音识别时，孩子开口后会自动打分（0–100），读对的词标绿、没读准的标红。85 分以上算 Perfect。
- 不支持时，自动切换成**录音自评**：录下自己的声音，和原音对比，再给自己打分。连麦克风都用不了时，改为“大声读 + 自评”。

**浏览器建议（中国大陆）**

- 电脑：**Microsoft Edge**（语音识别走微软服务，国内一般可用）
- iPhone / iPad：自带的 **Safari**
- Chrome 的语音识别依赖 Google 服务器，在国内通常连不上，游戏会自动切到录音自评
- 微信内置浏览器一般不支持语音识别，建议用“在浏览器中打开”

朗读使用浏览器自带的英语语音，可以在「设置」里换声音、调语速。

## 运行

直接双击 `index.html` 就能玩。如果麦克风权限有问题，可以起一个本地服务器再打开：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

也可以开启仓库的 GitHub Pages，用手机直接访问。

进度（星星、金币、宠物、错题本）只保存在当前浏览器里，换设备或清理浏览器数据会丢失。

## 家长 / 老师

- 「设置 → 家长 / 老师模式」可以直接开放全部关卡，跟着课本进度练某个单元。
- 题目内容都在 `data.js`，按格式增删单词、句子、对话即可，不用改游戏代码。

## 文件

- `index.html` 页面结构
- `style.css` 样式
- `data.js` 13 座岛的单词、句子、对话
- `game.js` 游戏逻辑：出题、朗读、语音识别与打分、奖励系统
