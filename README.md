# 回声岛 Echo Island

给初一（七年级）学生的英语**听说**闯关游戏。纯网页，不用安装、不用服务器，打开 `index.html` 就能玩。

## 怎么玩

首页有两个标签：**🐲 怪兽冒险**（主玩法）和 **📚 闯关练习**。

### 🐲 怪兽冒险（像宝可梦一样的 RPG）

- 先从火苗狗、泡泡鱼、小芽芽里选一只当伙伴，要对它大声说 “I choose you!”
- 然后走进**冒险世界**（2.5D 画面：3D 的小镇、树、房子和岩壁，人物是可爱的纸片小人）：用方向键走路，按 **A** 和人说话、看告示牌、进门，按 **B** 打开菜单（电脑上可以用方向键 / WASD、空格）。你的主力怪兽会跟在身后
- **13 个小镇 + 12 条道路 + 3 个洞穴**，每个小镇对应一个七年级话题，镇上的人说的英语、战斗里的咒语都来自这个话题
- 每个小镇里的房子都能进去：
  - 🏥 **怪兽中心**：找护士免费恢复体力；旁边的**电脑**能把怪兽存进箱子、换队伍。怪兽的体力会一直保留，全队累倒会被送回中心
  - 🏪 **商店**：回声球、药水，越往后的小镇卖的越多（超级球、好伤药、复活草、驱怪喷雾、逃生绳）
  - 🏟️ **道馆**：里面有道馆训练师，最里面是馆主。打败馆主拿徽章，北边路口的守卫才会放你走上下一条路
  - 🏠 **民居**：村民请你跟着说一句，或者看图说单词，每天可以领奖励
  - 👩‍🔬🧑‍🏫 **镇上的人**：用英语和你聊天、出题
- 小镇之间是**道路**：
  - 🌿 **草丛**：走进去会遇到野生怪兽
  - 🧑‍🎤 **训练师**：看到你就会走过来挑战
  - ⤵️ **台阶**：只能往下跳
  - 🕳️ **洞穴**：有的路边有洞口，里面很黑，怪兽更强
  - 🔮 地上的道具，走过去就能捡
- **队伍最多 6 只**，多出来的怪兽送进电脑箱子；**背包**里的道具在大地图和战斗里都能用
- **画质**：设置里可以选 自动 / 精美 / 标准 / 省电 / 2D 流畅。自动会先用标准，手机跑不动就降一档
- **战斗**：攻击靠说（说单词是小技能，念句子是中技能，攒满 3 格能量能放对话大招），防御靠听（12 秒内听懂对手的咒语）。念得越准伤害越高，特别准会暴击
- **属性克制**：🔥 克 🍃，🍃 克 💧，💧 克 🔥，⚡ 克 💧
- **收服**：把野生怪兽打虚弱后扔回声球，念出收服咒语。一共 16 种怪兽，收集进图鉴
- **升级进化**：打赢得经验，Lv 10 进化成更强的样子
- 回声球除了在商店买，也在闯关练习里赚：每通关一关 +1，三星 +2
- 去过的小镇可以在首页「飞回去」

### 📚 闯关练习


- **13 座小岛**，每座岛对应七年级的一个常见话题：问候、文具颜色、家庭、学校、学科、社团、作息、生日、动物、规则、运动饮食、天气、过去的经历。
- 每座岛 **7 关**，从易到难：听词 → 说词 → 听句 → 说句 → 对话 → 综合挑战 → **Boss 对话战**。打败 Boss 解锁下一座岛。
- 题目每次随机生成，重玩不会一模一样。

每座岛的地图最上面还有一集 **🎬 对话动画片**：画出来的卡通角色（Lily、Tom、王老师、面馆服务员）在教室、客厅、动物园、面馆等场景里，用不同的声音演一段 6–8 句的情景对话。说话时嘴巴会动、会做手势，有片头和结尾挥手，带中英文字幕。有三种看法：

- **看动画**：完整看一遍；可以关掉英文字幕练纯听力，点对话记录能单独重听一句
- **跟读**：每句播完停下来，孩子跟着说一遍，说对了自动继续
- **角色扮演**：选一个角色，轮到自己时大声说台词，另一个角色由电脑演

第一次看完 +10 金币，完成角色扮演 +30 经验 +10 金币。进「对话」关之前也会提示先看动画。

| 听力题 | 口语题 |
| --- | --- |
| 听音选义、听音选词、听句选意、听问选答、听音排句 | 单词跟读、句子跟读、看图说英语、说出回答、Boss 对话攻击 |

## 让孩子想继续玩的设计

- **连击**：连续答对 3 / 5 / 10 题，经验 ×1.5 / ×2 / ×3，音效越来越高
- **星星**：不丢心、答对 90% 以上拿三星；首次三星额外奖励金币
- **等级和称号**：见习水手 → 听力侦探 → 口语新星 → …… → 传奇船长
- **连续打卡**：每天完成一关就算打卡；**连胜保护卡**可以自动补一天
- **每日任务 + 宝箱**：每天 3 个任务，做完开宝箱，可能开出商店里买不到的限定宠物
- **宠物店**：用金币买宠物，宠物会在地图上陪着闯关
- **幸运暴击**：通关时有 15% 概率金币翻倍
- **26 个成就**、**错题本**（答错的题自动收集，复习答对就移除）
- **3 颗心 + 复活**：心用完可以花金币复活一次

也有照顾孩子的设计：连续玩 30 分钟会弹出 20 秒的**护眼休息**；口语题说不好**不扣心**，最多试 3 次后自动放进错题本。

## 口语打分

- 浏览器支持语音识别时，孩子开口后会自动打分（0–100），读对的词标绿、没读准的标红。85 分以上算 Perfect。
- 不支持时，自动切换成**录音自评**：录下自己的声音，和原音对比，再给自己打分。连麦克风都用不了时，改为“大声读 + 自评”。

**浏览器建议（中国大陆）**

- 电脑：**Microsoft Edge**（语音识别走微软服务，国内一般可用）
- iPhone / iPad：自带的 **Safari**
- Chrome 的语音识别依赖 Google 服务器，在国内通常连不上，游戏会自动切到录音自评
- 微信内置浏览器一般不支持语音识别，建议用“在浏览器中打开”

朗读优先用手机/浏览器自带的英语声音。很多安卓浏览器（微信、华为、小米自带浏览器）没有英语声音，这时会自动改用**有道在线发音**（需要联网）。也可以在「设置 → 发音来源」里手动切换。有道发音接口不是官方开放接口，以后可能会变。

在微信里打开时，建议点右上角「···」→「在浏览器打开」，录音和语音识别会更稳定。

## 运行

直接双击 `index.html` 就能玩。如果麦克风权限有问题，可以起一个本地服务器再打开：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

### 用 GitHub Pages 在手机上玩

1. 仓库需要是**公开**的（私有仓库开 Pages 需要付费的 GitHub Pro）：Settings → General → 最下方 Danger Zone → Change visibility → Public
2. Settings → Pages → Build and deployment → Source 选 **Deploy from a branch**，Branch 选 `claude/english-learning-game-l52ev8`（合并到 main 后改选 `main`），文件夹选 `/ (root)`，点 Save
3. 等 1–2 分钟，访问 **https://dqq12125-glitch.github.io/private-note-/**

`github.io` 在国内大多数时候能直接打开，但偶尔会慢或打不开；如果需要非常稳定，可以放到国内云服务的静态托管（需要备案域名）。

进度（星星、金币、宠物、错题本）只保存在当前浏览器里，换设备或清理浏览器数据会丢失。

## 家长 / 老师

- 「设置 → 家长 / 老师模式」可以直接开放全部关卡，跟着课本进度练某个单元。
- 题目内容都在 `data.js`，按格式增删单词、句子、对话即可，不用改游戏代码。

## 文件

- `index.html` 页面结构
- `style.css` 样式
- `data.js` 13 座岛的单词、句子、对话，以及 13 段对话动画的台词（`SCENES`）
- `cartoon.js` 对话动画片的卡通角色、场景，以及怪兽造型（SVG 绘制，没有图片文件）
- `monsters.js` 怪兽对战：图鉴、战斗、收服、升级进化、馆主、训练师
- `maps.js` 全部地图数据（小镇、道路、洞穴、室内和出入口）
- `world.js` 冒险世界逻辑：走路、跳台阶、进门、草丛遇怪、训练师视线、怪兽中心/电脑、商店、道馆、守卫、英语对话框；2D 流畅模式
- `world3d.js` 2.5D 画面（three.js，库文件在 `vendor/`，不依赖外网）
- `game.js` 游戏逻辑：出题、朗读、语音识别与打分、奖励系统、对话动画播放
