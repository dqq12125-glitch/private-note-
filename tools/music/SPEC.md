# 回声岛配乐规格（作曲 + 合成引擎共用）

游戏的背景音乐和小段音乐**全部用代码现场合成**（WebAudio），不用音频文件：APK 不变大、没网也能放、没有版权问题、可以随时压低音量给英语朗读让路。风格：**GBA 掌机 RPG**（方波/三角波/噪音鼓 + 一点点回声），明亮、好记、听很久不烦。

文件：
- `music-core.js`（已写好，不要改）：乐谱格式的解析 `timeline()` 和检查 `check()`。
- `tools/music/songs/<id>.js`：**一首一个文件**，`module.exports = { … }`。
- `node tools/music/build.js <id> [<id>…]`：检查这几首，打印报告（错误必须改到 0）。`node tools/music/build.js` 检查全部并生成 `music-data.js`（`window.MUSIC.songs`）。
- `music.js`（引擎，`window.EchoMusic`）：合成器 + 播放器。
- `tools/music.html`：试听页（每首一个按钮，显示正在放第几小节）。

## 1. 乐谱格式

```js
module.exports = {
  id: 'route',                 // 和文件名一样
  title: 'Route Song',         // 英文名
  zh: '出发吧！',               // 中文名（试听页显示）
  use: '1–5 岛的道路',          // 在游戏里哪里放
  bpm: 132,                    // 每分钟几拍（四分音符一拍）
  meter: 4,                    // 每小节几拍（四分音符算）：4 = 4/4，3 = 3/4（6/8 也写 3，用八分音符写节奏）
  key: 'G', mode: 'major',     // 调：C C# Db D … B；mode：major minor harmonicMinor melodicMinor dorian phrygian lydian mixolydian pentatonic minorPentatonic blues wholeTone chromatic
  loop: true,                  // 背景音乐 true；一次性的小音乐（胜利、升级…）false
  loopFrom: 1,                 // 循环回到 order 的第几项（0 开始）。前面的是只放一次的前奏
  swing: 0,                    // 0–0.33：八分音符摇摆（0.33 ≈ 三连音的长短）
  drumGrid: 4,                 // 鼓的格子：每拍 4 格（十六分）；三连音/shuffle 的歌写 3
  inst: { lead: 'pulse25', harm: 'pulse50', arp: 'pulse12', bass: 'tri' },   // 每个声部的音色（用到的声部都要给）
  mix: { lead: 0.9, harm: 0.45, arp: 0.35, bass: 0.85, drums: 0.6 },          // 可选，0–1，每个声部的音量
  fx: { echo: 0.25 },          // 可选：旋律的回声（延迟）多少，0–0.5，「回声岛」的招牌味道，别太大
  sections: {
    I: { lead: [ … ], bass: [ … ], drums: [ … ] },          // 一个段落：每个声部是「一个字符串 = 一小节」的数组
    A: { lead: [ … ], harm: [ … ], arp: [ … ], bass: [ … ], drums: [ … ] },
    B: { … },
  },
  order: ['I', 'A', 'A', 'B', 'A'],   // 段落顺序；同一段可以重复用
};
```

**音符**（空格隔开，一小节加起来必须正好 `meter` 拍）：
- `C5/8`：音名 + 八度（C4 = 中央 C）/ 时值。`#` 升、`b` 降：`F#4/4`、`Bb3/2`。
- 时值：`1` 全音符 4 拍、`2` 二分 2 拍、`4` 四分 1 拍、`8` 八分、`16` 十六分、`32`；三连音 `12`（八分三连音，三个一拍）、`6`（四分三连音，三个两拍）、`24`、`3`。附点加 `.`：`4.` = 1.5 拍。连音线用 `+`：`2+8` = 2.5 拍。
- 休止：`r/4`。
- 和弦（只能在 `harm`、`arp`，最多 4 个音）：`[C4 E4 G4]/2`。
- 结尾记号：`^` 断奏（只发一半长度），`!` 重音。例：`G4/8^`、`C5/4!`。

**声部和音域**（MIDI 号，超出算错误）：
| 声部 | 用途 | 音域 |
| --- | --- | --- |
| `lead` | 主旋律（单音） | G3–C7（55–96） |
| `harm` | 和声、副旋律、长音（可以和弦） | A2–C6（45–84） |
| `arp` | 分解和弦、琶音、点缀（可以和弦） | E3–E7（52–100） |
| `bass` | 低音（单音） | E1–D4（28–62） |
| `drums` | 鼓：`k` 底鼓 `s` 军鼓 `h` 闭镲 `o` 开镲 `c` 吊镲 `t` 低嗵 `T` 高嗵 `.` 空，一小节 `drumGrid × meter` 个字符 | |

一个段落里，写了的声部小节数要一样；没写的声部这段就是休止。

**音色**（引擎提供）：
| 名字 | 声音 | 适合 |
| --- | --- | --- |
| `pulse12` | 12.5% 方波，尖细 | 点缀、琶音（别长时间放高音） |
| `pulse25` | 25% 方波，GBA 主旋律的标准声音 | 主旋律 |
| `pulse50` | 50% 方波，厚 | 和声、副旋律 |
| `tri` | 三角波 | 低音（标准）、柔和的旋律 |
| `wave` | GB 波形表的软方波 | 低音、副旋律 |
| `bass` | 带一点咬合的合成低音 | 战斗、快歌的低音 |
| `saw` | 柔和的锯齿波（过了低通） | 和声、铺底 |
| `sine` | 正弦波 | 很柔和的旋律、学习音乐 |
| `flute` | 带颤音和气声的笛子 | 抒情旋律、雪岛、学习 |
| `bell` | 钟琴（FM） | 点缀、魔法、进化、学习 |
| `pluck` | 拨弦（竖琴/吉他） | 琶音、小镇 |
| `marimba` | 木琴 | 欢快的小镇、学习 |
| `organ` | 风琴 | 神殿、冠军 |
| `strings` | 弦乐铺底（慢起慢收） | 和声长音、史诗段落 |
| `brass` | 铜管 | 号角、胜利、岛主战 |

引擎自动做的：长音（≥ 1 拍）的旋律加延迟颤音；每个声部有固定的左右位置；整体有压限，不会爆音；循环无缝（`loopFrom` 那一拍接上）。

## 2. 作曲要求（必须遵守）

1. **完全原创**。不能引用、改编、模仿任何现成的旋律：任何现成游戏系列的城镇、道路、战斗、胜利、恢复、升级、进化音乐都不行（任天堂/史克威尔等）、迪士尼和动画歌曲、流行歌、儿歌（小星星、生日歌、两只老虎…）、古典名曲。可以用同样的**风格**（和声进行、配器、节奏型），但旋律轮廓必须是自己写的。写完自己检查：前两小节的音程走向和节奏，是不是像哪首有名的曲子。
2. **孩子听很久也不烦**：背景音乐循环 40–100 秒（检查器会算），有 A/B 两段以上的对比；旋律要「能哼出来」——短动机 + 重复 + 变化，句子 2/4 小节一句、问答呼应；别堆满十六分音符。
3. **给英语朗读让路**：游戏里一直有英语朗读和孩子开口说话。小镇、室内、学习类的旋律不要太密（检查器的「旋律 个/秒」小镇 ≤ 3.5、学习 ≤ 2.5），中音区别一直塞满；引擎朗读时会把音乐压低，但旋律本身也要留呼吸。战斗可以更密更燃。
4. **循环接缝**：最后一小节要能自然接回 `loopFrom` 那一小节（一般结束在属和弦/属音上，或者用过门鼓）。不要在循环点留一整小节的空白。
5. **和声清楚**：强拍上旋律和低音/和声别撞小二度、大七度、三全音（检查器的「强拍刺耳」最好 ≤ 8%，经过音放弱拍）。低音走根音/五音为主，和声用三和弦、七和弦，进行要有方向（I–IV–V、vi–IV–I–V、ii–V–I、i–VI–III–VII 等，可以用借用和弦、二级属）。
6. **检查器 0 个错误**；提醒要么改掉，要么在文件开头的注释里说明为什么故意这样。
7. 文件开头写注释：曲名、在哪里放、情绪、结构（例如 `I(2) A(8) A'(8) B(8) → 回 A`）、和弦进行概要、用到的回声主题在哪里。

## 3. 回声主题（全游戏的招牌动机）

给几首重要的曲子一个共同的「家族」味道。主题叫「推拍回声」（Push & Wedge），C 大调写法，用的时候移到自己的调：

```
呼：E5/8 F5/8 D5/8 G5/4.! r/4 | F5/8 E5/8 G5/8 D5/2+8        简谱 3 4 2 5~ (休) | 4 3 5 2~~
应：G5/8 A5/8 F5/8 C6/4.! r/4 | F5/8 E5/8 G5/8 C5/2+8        简谱 5 6 4 1'~ (休) | 4 3 5 1~~
和弦：C | Dm7 → G | C/E → F | G7 → C        （每小节第二个和弦都换在「推拍」那个长音上）
低音：C3 | D3 → G2 | E2/4 C2/8 F2/2+8 | G2 → C3   （第 3 小节低音要走：E 只托第 1 拍，F5 那一下底下是 C，长音上才是 F）
```

**认它的三个指纹**（改编时至少留住第 1 条）：
1. **推拍节奏**「嗒嗒嗒 当——」：三个八分音符，第四个长音提前半拍落在第 2 拍的后半拍（and-of-2），跨过第 3 拍。第 1、3 小节长音后面休止一拍（`fx.echo` 正好在那里回一声），第 2、4 小节长音拖到小节线。四个小节节奏完全一样，光拍手打这个节奏就认得出来。
2. **楔子**：头四个音 mi-fa-re-SOL（+1 −3 +5）：半音上去、往下越过起音、再往上推四度，像水波往外开。
3. **镜像 + 回声**：第 2 小节是第 1 小节的倒影（fa-mi-sol-RE，−1 +3 −5）；「应」第 1 小节前三个音是「呼」高三度（sol-la-fa），推拍那个音再高一级到 do'（+2 −4 +7）；第 2 小节和「呼」第 2 小节一样，只把最后的 re 换成 do——问句变成完全终止。「呼」只在 D5–G5 一个四度里，最好唱。

**片段规则**：引用片段时，**推拍节奏才是指纹**——要么用 E-F-D-G 加推拍（长音在 and-of-2），要么只用推拍节奏配别的音高；光有音高的「mi-fa-re」太常见，没人认得出。

**禁区**（都会滑到有名的曲子上）：
- 别在主题头前面加往上的音阶引子（`C5/16 D5/16 E5/8 F5/8 D5/8 … G`）——那是巴赫《二部创意曲》第 1 首的主题 C-D-E-F-D-E-C-G。**接缝也算**：前奏、上一段或循环的最后一小节如果以 do-re（或者一个 re）收尾、中间不休止就接主题头，连起来就是 do-re | mi-fa-re-sol；让接进来的那个音从上面落到 mi（比如 sol → mi），或者先休止一下。
- 「应」的头 sol-la-fa 后面别往下掉八度再落到低音 do（G-A-F-低八度 F-低音 C，就是《第三类接触》的五音信号；头两个音程 +2 −4 本来就一样），也别把这几个音写成一样长；do' 永远往上跳。
- 别写同音反复的变体（`E5/8 E5/8 E5/8 G5/4.`、「E E E C~」）——会滑向马里奥地上关、贝多芬第五。
- 别把四个音拉成一样长的四分音符（`E5/4 F5/4 D5/4 G5/4`），尤其是钟琴——像大本钟的报刻（E C D G | G D E C），也丢了推拍。
- 「呼」的第 2 小节和声保持 Dm7 → G，别配成光秃秃的 C | G：「呼」本来就和《欢乐颂》同一个框（D–G 的四度、从 E 开始、停在 D 上），再配 I–V 就太像了。
- 进行曲版第 3 小节「G A F C'」里 A → F 往下那一步要听得出来，别抹平成 G A B C'（《夺宝奇兵》进行曲）。
- 对比段（B 段、展开段）别再用推拍节奏，改成直的四分音符或长音，让推拍保持「特别」。

**变形**（都已经按各曲的调和速度写进去了；`!` 重音按需要去掉）：
- 小调版（A 小调写法，配 Am | Dm → E，E 用和声小调的大三和弦）：`C5/8 D5/8 B4/8 E5/4.! r/4 | D5/8 C5/8 E5/8 B4/2+8`；应 `E5/8 F5/8 D5/8 A5/4.! r/4 | D5/8 C5/8 E5/8 A4/2+8`（Am → Dm | E7 → Am）。快的时候推拍那个音当铜管的短促重击，弦乐在下面把同一个音拉长；别配「E B C D C B A」那种八分音符方波固定音型（俄罗斯方块味），低音用推拍节奏打根音（或主音 / 属音持续音）。
- 号角版（胜利、徽章）：`E5/8 F5/8 D5/8 G5/4.! r/4 | G5/8 A5/8 F5/8 C6/2+8!`（C | G7 → C）。第二支铜管低三度平行：`C5/8 D5/8 B4/8 E5/4.! r/4 | E5/8 F5/8 D5/8 G5/2+8!`（B4 是弱拍经过音）。第 1 小节和声不换，推拍那一下要全体重击（铜管和弦 + 定音鼓），第 1 拍加吊镲/定音鼓给个开场。「应」的尾巴高八度收：`F5/8 E5/8 G5/8 C6/2+8!`。三首号角开头各不一样（同一个主题切不同的刀）：`win` = 「呼」的头 + 「应」的头（两支铜管）；`badge` = 「应」的头（附点进行曲步子）→ 同样的附点步子高一级（A. B♭ G D'＝la-♭si-sol-RE'：「呼」的楔子 +1 −3 接「应」的 +7 跳，配 IV → ii7；推拍上的 D' 是 Dm7 的根音，后面不出现 B 还原，免得 B♭/B 对斜；B♭ 也别改成 B 还原，那样更像《夺宝奇兵》进行曲）→ 「应」的尾巴高八度收（V7 → I）；`victory` = 只用两句的尾巴（第 2、4 小节那种「fa mi sol RE / DO」），前面配新的跳音句。
- 进行曲版（勇气之路）：附点放在前面、推拍留着：`E5/8. F5/16 D5/8 G5/4.! r/4 | F5/8. E5/16 G5/8 D5/2+8 | G5/8. A5/16 F5/8 C6/4.! r/4 | F5/8. E5/16 G5/8 C5/2+8`，军鼓/定音鼓打在推拍上。
- 空灵版（进化）：节奏不加倍（加倍成四分音符就丢了推拍，还像大本钟），慢速下原节奏已经够慢：`E5/8 F5/8 D5/8 G5/4. r/4 | F5/8 E5/8 G5/8 D5/2+8`，不加重音，`fx.echo` 0.4 左右填满休止；「要进化了」的上升用主题头一小节一小节往上移全音：`E5/8 F5/8 D5/8 G5/4. r/4 | F#5/8 G5/8 E5/8 A5/4. r/4 | G#5/8 A5/8 F#5/8 B5/4. r/4`。利底亚的曲子（`evolve` 是 F 利底亚）把主题放在「C 那一层」原样不动：F 利底亚的音就是 C 大调那七个音，主题只用 1–6 级，一个调外音都不用，和声换成利底亚的 F → G。第 4 小节配 G → F（II → I），别配 G → C（那是 C 大调的完全终止：整段会听成 C 大调，「要进化了」的期待也提前放掉了）。
- 小镇（`town_a`）：只用「应」那两小节，`fx.echo` 回一声；要更省就只用 `G5/8 A5/8 F5/8 C6/4. r/4`。

**教孩子唱的词**（每句最后一个重读的词落在推拍的长音上，其他重读音节落在第 1 拍或第 2 拍；对唱小游戏里用）：
```
呼：Hel-lo, hel-LO! / Are you out THERE?
应：Hel-lo, my FRIEND! / Yes, I'm right HERE!
```
（大写的是推拍上的词。）第 2 小节：fa 上 Are / Yes（第 1 拍）、mi 上 you / I'm（弱）、sol 上 out / right（第 2 拍，这一小节最高的音，一定要放重读的词）、推拍上 THERE / HERE。there / here 押韵，正好教「打招呼 + 一般疑问句 + 回答」。不用「Is some-one THERE? / Yes, I am HERE!」：第 2 拍的高音会把 some-one 唱成 some-ONE、把 I am 唱成强读的 I AM——正好是中国孩子最常犯的重音错误。第 1 小节「Hel-lo」的 hel 落在第 1 拍不要紧，音高在 lo 上往上走，听起来还是 hel-LO。不用「Hel-lo, Is-LAND!」（推拍会把重音放在 -land 上，英语是 IS-land），也不用「Can you hear me?」（「Hello… can you hear me」是 Adele《Hello》的歌词）。孩子开口唱时放低一个八度：「呼」D4–G4，「应」到 C5，变声前后的嗓子都舒服。

「呼—应」本身就是回声的意思：一句话说出去，岛会把它「回」过来。用到主题的：`title`（完整）、`town_a`（「应」的片段）、`victory`/`win`/`badge`（号角版，三首开头不一样）、`league`（进行曲版）、`battle_boss`（小调版）、`evolve`（空灵版）。其他曲子不用。

## 5. 引擎接口（`music.js`，给游戏用）

```js
EchoMusic.play(id)        // 换背景音乐（交叉淡出淡入；同一首正在放就什么都不做）。id 为 null/'' = 淡出停止
EchoMusic.jingle(id)      // 放一次性的小音乐：背景音乐暂停（淡出），放完接着放原来那首（或者期间 play() 换掉的那首）。返回 Promise
EchoMusic.duck(on)        // 英语朗读开始/结束：音乐压到 30%（计数，嵌套安全）
EchoMusic.hold(on)        // 麦克风在听：音乐完全静音（计数）——防止被录进去影响打分
EchoMusic.setVolume(v)    // 0–1；0 = 关
EchoMusic.current         // 正在放的 id
EchoMusic.songs()         // 曲目列表（试听页用）
```
- 第一次点屏幕/按键时才创建 AudioContext（浏览器的自动播放规定）。
- 页面隐藏（切到后台、锁屏）时暂停，回来接着放。
- 在自动化测试里（`navigator.webdriver`）默认不出声，除非网址带 `?music`。
