## 拿不准、请母语审读重点看的地方

- **何 的读法**：按后面的音定——何ですか / 何時 / 何人 / 何さい / 何階 / 何の = なん；何を / 何が / 何色 = なに。**何部** 写了 なにぶ（学生之间最常听到），なんぶ 也有人说。**何階** 写 なんがい（なんかい 也可以）。
- **十さい** 写了 じゅっさい（现在最普遍；传统规范是 じっさい）；**十本** 写 じゅっぽん（同理，也有 じっぽん）。
- **わたし** 写假名、**ぼく** 给男孩子用；没有教 あなた。成人学的人可能需要 わたし 之外的说法（わたくし）——放到 3 级敬语单元。
- **家人的叫法**：小镇统一用 お父さん・お母さん・お兄さん（孩子对外人也这么说），对外人谦称的 父・母・兄 放到 1 级第 1 单元。成人学的人如果在小镇里说「わたしのお母さんです」会显得孩子气——大纲里写明了，1 级要尽早讲。
- **友だち**：按日本小学课本写法，没写 友達。两种都对，选了课本写法；如果以后统一成 友達，记得 1–3 级一起改。
- **问句用「？」**：日本的儿童读物和游戏里「〜ですか？」很常见，但正式书面语是「〜ですか。」。这里为了让学的人一眼看出是问句而选了「？」。
- **「自転車のときは、ヘルメットをかぶってください」**：口语里这样说没问题，更完整的是「自転車に乗るときは」，但「辞書形＋とき」要到 2 级才学，先用了简单的说法。
- **「サッカーは十一人です」**（第 5 岛的错误选项）：口语可以，更完整是「十一人でします」。只是干扰项，留着。
- **「ごみはどこにすてますか？」**：母语者更常说「どこにすてればいいですか」，但〜ば是 3 级的语法，先用简单问法。
- **「どうしてですか？」/「〜ですから。」**：第 4 岛、第 8 岛的场景里用「歌が好きですから。」「かっこいいですから。」，口语里常见；书面上 「好きだからです」更标准，到 3 级常体时再讲。
- **意思不好对译的**：
  - よろしくおねがいします：中文「请多关照」、英文统一给 Nice to meet you（首次见面的场合），其他场合的用法没在小镇里出现。
  - すみません：中文「不好意思」、英文 excuse me；道歉的用法没单独教。
  - 理科：中文写「科学课」，英文 science（日本的「理科」= 中小学的科学课）。
  - 社会：「社会课」/ social studies。
  - 一階 / 二階：英文按美式写 first floor / second floor（日本的一階 = 地面那层），英式英语的学的人可能会误会。
  - 楽しかった 作为单词给了「（过去）很开心 / was fun」。
  - 半：中文给了「半（30分）」/ half past。
- **信号 的颜色**：日语里绿灯叫「青」，这里只出现了红灯（赤），以后讲到绿灯要提醒「青信号」。
- **人名的中文**：ゆい→由衣、はると→晴人、そうた→宗太、あおい→葵、けん→健、ひな→阳菜、りく→陆、まい→麻衣、たくみ→拓海、はな→小花、田中先生→田中老师。日语原名没有确定的汉字，这里只是常见写法。
- **配音提醒**：读音栏 r 里助词照写法写「は／へ／を」。如果配音或识别直接拿 r 合成，会把助词 は 念成 ha——**请用原文 t 合成**，或者在合成前把助词 は・へ 换成 わ・え。
- 小镇整体比英语版略简单（日语初学者要同时学假名），第 9 岛的〜てください、〜てもいいですか 是整块教的，能不能接受、要不要往后挪，请老师判断。

### 这一轮改了什么（只改了 5 处，都是小地方）

1. **第 7 岛 词「カード」的图**：💌（情书）→ ✉️。情书有恋爱含义，不适合全年龄；✉️ 是信封，认「贺卡」够用。
2. **第 1 岛 对话 0 的正确答案 英文**：`These are scissors.` → `This is a pair of scissors.`。日语 これははさみです 是单数「这是一把剪刀」，原来的复数英文会让人以为 これ 是复数。
3. **第 9 岛 岛主开场 英文**：`Can you run in the hallway?` → `Is it OK to run in the hallway?`。日语是「可不可以」（〜てもいいですか），原来的 Can you 会被读成「你能不能跑」（能力）。中文本来就是「可以……吗」，没动。
4. **第 5 岛 句 4 中文**：`由衣画画真好。` → `由衣画得真好。`（原句生硬，改成通顺的说法）。
5. **第 2 岛 场景 英文**：`my mom` → `my mum`。全文英文按英式拼写（colour、favourite、Mr），只有这一处是美式。

### 拿不准、没有改（请母语审读或老板定）

- **🙏（第 0 岛 ありがとう）**：在日本是「谢谢／拜托」，但在别的文化里是祈祷，有宗教联想。全年龄、多国的产品里要不要换成 😊 或 🤝，请老板定。
- **❤️（第 4 岛 好き）**：只是普通的心形，没有明确的恋爱含义，但「喜欢」配红心，成人学习者可能读成「爱」。可换成 👍。
- **🥵（第 11 岛 暑い）**：本意是「热得脸红」，网上有擦边用法，给孩子用最好换成 🔥 或 🌡️。
- **🪜（第 3 岛 かいだん）**：这是「梯子」不是「楼梯」，表情里没有楼梯；可以接受，也可以改成 🏢 加上词义靠中文说明。
- **🗓️ / 📆 / 📅（第 7 岛 何月・何日・カレンダー）**：三个都是日历，只看图分不开。该岛三个词只能靠文字区分，如果以后做「看图选词」要避免这三个同时出现。
- **🧑‍🤝‍🧑（第 0 岛 友だち）**：「牵手的人」，有的系统显示成情侣姿势；建议确认各平台显示，或换 👫 之外的「两个人」类图（注意不要选 👫👬👭）。
- **🚶 重复**：第 0 岛 さようなら 和第 6 岛 行きます 都是 🚶，不同岛所以不冲突，只是提醒。
- **「Mr Tanaka」**：田中先生的性别没有定，英文写了 Mr。中文「田中老师」是中性的。如果想中性，英文可用 Tanaka-sensei。
- **げんき 写假名**：元気 的两个字（元 2 年级、気 1 年级）都在范围内，按规则可以写汉字；作者全文统一写假名（第 0 岛只出现这一个词），不算错，只是和「范围内的字照常写汉字」的做法略不一致。要不要统一请定。
- **第 9 岛 场景「先生みたいですね」**：〜みたい 要到 3 级才系统学；这一句整句有中文英文对照，不影响答题，但如果要严格按大纲，可改成「まいさん、先生ですね！」。
- **第 3 岛 前后设定**：しょくどうは図書室の前（句 7）和 図書室は二階、ほけんしつ・しょくどうは一階（句 2、对话 3、场景）。「前」可以理解成同一座楼的前面，不算矛盾，但读者可能会问食堂到底在几楼，必要时把句 7 改成「しょくどうは体育館の前です」。
- **第 10 岛 对话 2 的错误选项**「体育館でします。」「毎日します。」：回答的是「在哪里／多久一次」，不是「什么运动」，语法对、答非所问，可以留；但学的人如果只看到「どんな」可能犹豫，必要时换成更明显离题的选项。

- **第 4 岛 「ぞう」「かめ」「さる」「くま」写假名**：象（4 年级）在范围内，但全文已统一写假名，同上，仅供统一时参考。

## 1 级单元的独立复核（2026-11-21）

没看过稿子的复核把 ja1-1 … ja1-8 逐条读了一遍。**没有发现读音错**（数字 + 量词、日期、钟点都对）；改的主要是词块切法不合约定、其实说得通的错误选项、不准的中英文意思。汉字范围是凭记忆看的，没有对字表；音高没查。只有机器复核，**不能代替**找母语的人看。

### 定下来的约定

- 名词后面的 です / でした / ですか 单独一块；この / あの 单独一块；「駅の｜前で」这种方位说法拆开。
- 角色的中文名一律写汉字：遥、大地、七海、莲、阳菜、陆、康太、枫；岛主彭太、胡桃、呼呼、段波。
- 英文意思用英式写法（maths、Mr、packed lunch）。
- 男孩子说 ぼく（れん 的开场白已改）。

### 改了的句子

- 「こちらはだれですか？」→「この人はだれですか？」（こちら 配 だれ 语体不搭）。
- 「船長はあの人ですか？」→「あの人は船長ですか？」（答句「はい、あの人は船長です。」才顺）。
- 「橋のうしろに森があります。」→「病院のうしろに…」（桥没有明显的前后）。
- 「博物館で昔の道具を見学しました。」→「昨日、博物館を見学しました。」（見学 的对象是地方）。
- 换掉的错误选项：「日本語の先生です。」「八時に学校へ行きます。」「ぞうが二ひきいました。」（都能算回答；大象也不用 ひき 数）。
- 「中国語」的图原来是麻将牌，拿掉了（没有图就不出看图题）；1 单元语法提示里「弟さん・妹さん」只用来说别人家的人。
