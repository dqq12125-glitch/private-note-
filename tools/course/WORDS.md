# 单词表、先认识再闯关、我的单词本、发音入门（2026-11-22）

老板：「应该做一个单词表出来的，不然完全的新手根本不懂那个语言，怎么学习呢？」

现在的样子：每个小镇 / 课本单元 7 关，第 1 关一进去就考「听音选意思」「听音选词」；能先看词的只有关卡详情里一个默认收起来的「📖 先预习一下」（game.js `levelSheet` 的 `<details class="pre">`）。没有单词表、没有「先学后练」、没有「学过的词都在哪」，别的语言的课也没有发音和文字的入门（日语假名、中文拼音和声调、西语字母和发音规则）。

这一轮做四样。**英语课也一起有前三样**（第四样只给西语、日语、中文）。不改关卡的结构（还是 7 关）、不改存档里已有字段的意思、不改打分。

## 1. 📖 单词表（每个小镇 / 课本单元一张）

- 从哪打开：闯关练习页每个小镇 / 单元卡片上一个显眼的「📖 单词表」按钮；关卡详情里原来那个收起来的「先预习一下」换成「📖 单词表」按钮（打开同一张表）；大地图冒险菜单里「现在这座岛的单词表」一行（可选，放得下就放）。
- 内容，按这个顺序：
  1. 标题：小镇 / 单元名（别的课：这门课的写法 + 界面语言小字，照 world.js `townTag` 的样子）。课本单元有 `grammar` 的，标题下面一块「这一单元的语法」（`grammar.title` / `grammar.tip`，按界面语言取）。
  2. **单词**（`words`，12 / 24 个）：每个一行或一张小卡——图（`pic` / 英语的 emoji）、**词**（大字，日语中文带读音：`E.ruby` / `rubyLine` 现成的那套）、**意思**（界面语言，`meanOf`）、🔊（点一下念，走 `say()`，课程包里有提前配好的声音）。日语另有一行**罗马字**（见第 5 条）。
  3. **例句**：每个词下面带一句这一课里用到它的句子（`sents` 里第一句含这个词的；西语按词、日语中文按子串），句子带读音、意思、🔊。找不到就不带。
  4. **常用句子**（`sents` 全部，可以收起）：句子、读音、意思、🔊。
- 每个词标一个小状态：🆕 还没练过 / 🔁 在复习 / ✅ 已掌握（读 `S.rev` 复习本，键怎么算照 game.js 现在的 `freeKey` / 复习本的规矩，别另造）。
- 竖屏一列、横屏两列；字号照现有弹窗；长表能滚，关闭按钮贴底。

## 2. 先认识再闯关（单词卡）

- 第一次点开一个小镇 / 单元的**第 1 关**（`li === 0`，这一关还没有星、这个小镇 / 单元还没看过单词卡）：先进「单词卡」，不直接开考。
- 单词卡：一次一张——大图、词（带读音；日语带罗马字）、意思，**出现时自动念一遍**（女声，再点 🔊 是男声，没有男声就女声）；← → 翻页（手机上左右滑也行），上面一排小点表示第几张；最后一张后面是「我认识了，开始闯关」。随时能点「跳过，直接闯关」。
- 看过就记一笔（存档 `S.seenCards[小镇或单元的编号] = 日期`，新字段在 `fresh()` 里给默认值 `{}`），以后第 1 关不再自动弹；单词表里有个「▶ 用单词卡过一遍」随时能再看。
- 课本单元有语法的，单词卡最前面一张是语法要点（标题 + 两三句，按界面语言）。
- 老存档：已经拿过第 1 关星星的不弹。测试存档（`tests/helpers.js` 造的）不能因为这个改变现有测试的流程——给测试用的设置一个开关（比如 `S.settings.cards === false` 或网址 `?nocards`），现有测试的存档默认带上它；只有新测试打开。

## 3. 📒 我的单词本

- 闯关练习页最上面一个入口「📒 我的单词本（学过 n 个词）」。
- 内容：学过的词（复习本里有的，加上拿过星的小镇 / 单元的全部单词），按小镇 / 单元分组（新的在上），每个词：图、词（读音）、意思、🔊、状态（🔁 / ✅）。顶上三个数：一共 / 在复习 / 已掌握；一个筛选：全部 / 在复习 / 已掌握；一个搜索框（按词或意思找）。
- 点一个词：展开例句（同第 1 条）。
- 别的课的单词本跟着那门课的存档走（每门课各自一本）。

## 4. 🔤 发音入门（只给西语、日语、中文）

完全零基础的人连字都不认识：日语要先认假名，中文要先懂拼音和声调，西语要知道字母怎么念。

- 入口：闯关练习页最上面（单词本旁边）「🔤 发音入门」；全新开始的人（这门课的存档里还没有任何星）首页给一张卡片「先学发音和文字（约 10 分钟）」。看过记 `S.primerSeen = 日期`。
- 内容来自课程包的 `course.json` 的 `PRIMER`（由 `tools/course/<语言>/primer.json` 生成，格式见下面）。页面：几段（section），每段标题 + 两三句说明 + 一张表（`grid`：像五十音图那样的格子；`list`：一行一个）；点任何一格 / 一行就念 `say`；有例词的点开看例词（词、读音、意思、图、🔊）。
- 日语：平假名、片假名（和平假名同一张表，小字显示）、浊音和半浊音、拗音（きゃ……）、长音 / 促音 / 拨音的说明各一段；每格显示假名 + 罗马字。
- 中文：四个声调 + 轻声（妈麻马骂吗）、声母、韵母、拼读（声母 + 韵母 = 音节，几个例子）、「一」「不」和三声的变调说明；每格显示拼音 + 例字。
- 西语：字母表（大小写 + 字母名 + 例词）、五个元音、和英语 / 汉语拼音不一样的发音（c / z、g / j、h 不发音、ll / y、r / rr、ñ、qu / gu、v 和 b）、重音和重音符号的规矩。

### `tools/course/<语言>/primer.json` 的格式

```json
{
  "lang": "ja",
  "sections": [
    {
      "id": "hira",
      "title": { "zh": "平假名", "en": "Hiragana" },
      "intro": { "zh": "两三句说明", "en": "Two or three sentences" },
      "layout": "grid",
      "cols": 5,
      "items": [
        { "t": "あ", "sub": "ア", "rom": "a", "say": "あ",
          "ex": [ { "t": "あめ", "r": "あめ", "zh": "雨", "en": "rain", "pic": "☔" } ] },
        null
      ]
    }
  ]
}
```

- `t` 大字；`sub` 小字（片假名 / 大写字母 / 例字）；`rom` 下面那行（罗马字 / 拼音 / 字母名）；`say` 点了念什么（要是 TTS 念得出、念得对的东西：日语写假名，中文写一个例字，西语写字母名或例词）；`zh` / `en` 可选的一句说明（声调怎么读、和英语哪里不一样）。
- `ex` 可选的例词：`t`（日语中文另写 `r` 读音）、`zh`、`en`、`pic`。例词尽量用这门课 `towns.json` / `units/` 里教过的词。
- `grid` 里空格子写 `null`（五十音图里 や行、わ行的空位）。`list` 不用 `cols`。
- 每门语言总共不要超过约 250 个 `say`（加上例词）。
- **声音（主会话 2026-11-22 实测后定）**：单个音（一个假名、一个字母名、一个汉字）本机合成和云端合成都念不准（本机多出尾音：あ→「わい」、妈→「买」；云端偶尔冒出几秒乱话），所以**条目的 `say` 用手机自带的语音念**（iPhone 自带日语、中文、西语的声音，念单音准、不用联网），没有这门语言的声音才退回课程的配音 / 云端合成；**例词（`ex[].t`）照常提前配音、打进课程包**。

### 生成

- `node tools/course/build.js <语言>`：有 `primer.json` 就并进 course.json 的 `PRIMER`（原样，加一个 `v: 1`），把每个 `say` 和每个例词的 `t` 加进配音名单 `VOICE`（女声）。`check.js`：格式、`grid` 的格子数是 `cols` 的倍数、日语 `rom` 只有 a–z 和 `'`、中文 `rom` 是带声调的拼音、例词的读音规矩同 lines.json。

## 5. 日语的罗马字

- `lang-ja.js` 加 `romaji(kana)`（平仮名、片仮名 → 平文式罗马字：shi chi tsu fu ji、ん 在元音和 y 前写 n'、促音双写下一个辅音（っち → tchi）、长音 ー 照前一个元音双写或加长音符号——选一种，全文统一，写在注释里）。`tests/lang.test.js` 加二三十条。

# 第二部分：零基础怎么学（老板 2026-11-22：「不只是单词表，完全不懂那个语言的人，怎么去学习？」）

第一部分（单词表、单词卡、单词本、发音入门）解决「看得到词、认得字」。零基础的人还缺三样：**有人告诉他每一课学什么、这些话怎么用**（现在的关卡几乎都是考，不是教）；**听不懂、说不出时能用的几句话**；**一条明确的路：第一天做什么、下一步做什么**。再加两个处处用得到的帮手：点一个词就看意思、朗读能放慢。

学习的顺序（新手路线就按这个排）：发音和文字 → 每一课先看「这一课学什么」→ 单词卡认词 → 听（第 1、3 关）→ 跟着说（第 2、4 关）→ 看对话动画 → 对话和 BOSS → 到大地图上用学过的话 → 和岛民聊天（岛民按级别说简单的话，学的人可以用「求助的话」）→ 每天复习。

## 7. 📘 这一课学什么（课前讲解）

每个小镇、每个课本单元一页，用**界面语言**讲（中文界面中文、英语界面英文），学的语言的句子带读音、意思、🔊：

- **学完能做什么**（一句）。
- **两三句说明**：这一课是什么场景、要学会说什么。
- **句型** 2–4 个：每个句型一张小卡——句型本身（空的地方写 `___`，例如 `Me llamo ___.`）、意思、一句怎么用的说明、1–2 个例句。**例句必须是这一课 `sents` / `dlgs` 里原样有的句子**（这样有现成的配音和读音；原文一字不差地抄）。
- **提醒** 0–2 条：这门语言和中文 / 英语不一样、新手最容易错的地方（例：日语动词放最后；西语名词分阴阳；中文没有时态变形，用「了」「过」）。
- 课本单元已经有 `grammar`（标题和讲解）：放在句型下面，不重写。

在哪：小镇 / 单元卡片上的「📘 这一课学什么」；第一次进第 1 关时，单词卡前面先看这一页（同一次「先认识再闯关」，第 2 条：讲解 → 单词卡 → 开始闯关）；单词表顶上有链接。看过记 `S.seenLesson[编号] = 日期`。

## 8. 🆘 求助的话

8–12 句零基础一定要会的话：听不懂、请再说一遍、请慢一点、这个用 X 语怎么说、是什么意思、对 / 不对、谢谢、对不起、我是新手…… 每句：这门语言（带读音）、意思、什么时候用、🔊。

在哪：发音入门的最后一段（学完发音马上学这几句）；聊天页面一个「🆘」按钮，点开就是这张表（点一句先听，再自己说出来——不替他发出去）；岛民的提示词里写明「学的人说了这几句里的任何一句，就照做：再说一遍 / 说慢一点 / 换简单的说法」（服务器那边主会话改）。

## 10. 👆 点一个词看意思

学的语言的句子（大地图对话框、闯关的题目和答案、对话动画的字幕、聊天里岛民和自己的话、单词表的例句）里，点一个词弹出小卡：词、读音、意思、🔊。查的是**这门课学过的词**（所有小镇和单元的 `words`，日语中文另加读音表里有意思的词）：西语按空格切、去掉标点，冠词和词形照 lang-es.js 的规矩配（找不到原形就不弹）；日语中文用这句话的 `seg` 词块（没有 `seg` 的按最长匹配课程里的词）。查不到的词不弹（不乱猜）。英语课一样（英语的词表）。

**2026-11-22 改（老板：「对话有点卡」）**：第一版在大地图对话框、聊天气泡、对话动画字幕里也是「点一下就弹」，可这几处点一下本来就有用（翻页、看翻译），点在字上十有八九碰到认得的词，卡片一直弹、对话翻不过去。现在这三处（game.js 的 `HOLD_SEL`）要**按住一个词约半秒**才弹，轻点照旧；按下去以后手指挪开 10 像素以上（在滑）不算；按住弹了卡以后松手那一下不翻页、不交给气泡。闯关题目、答完那一行、单词表 / 课前讲解的例句、求助的话照旧点一下就弹（按住也行）。聊天气泡和字幕长按不选字、不弹系统菜单（style.css）。测试 `words.test.js --only=p2` 的 §10。

## 11. 🐢 朗读慢一点

设置里「朗读速度：正常 / 慢」（`S.settings.slow`）：慢 = 课程配音以 0.8 倍速放（保持音高）、本机语音 rate 0.8；单词表、单词卡、课前讲解、发音入门里每个 🔊 旁边另有一个 🐢 按钮只这一次放慢。零基础（第 0 级）默认是「慢」。

## 12. 内容文件：`tools/course/<语言>/lessons.json`（英语：`tools/course/en/lessons.json`）

```json
{
  "lang": "es",
  "help": [
    { "t": "No entiendo.", "zh": "我听不懂。", "en": "I don't understand.", "use": { "zh": "听不懂的时候说", "en": "Say this when you don't understand." } }
  ],
  "towns": {
    "0": {
      "can": { "zh": "…", "en": "…" },
      "intro": { "zh": "两三句", "en": "Two or three sentences" },
      "patterns": [
        { "p": "Me llamo ___.", "zh": "我叫___。", "en": "My name is ___.",
          "note": { "zh": "…", "en": "…" },
          "ex": ["Me llamo Ana.", "¿Cómo te llamas?"] }
      ],
      "tips": [ { "zh": "…", "en": "…" } ]
    }
  },
  "units": { "es1-1": { "patterns": [ … ], "tips": [ … ] } }
}
```

- 日语、中文的 `help[].t`、`patterns[].p` 另写 `r`（读音，句型里 `___` 原样留着）。`ex` 只写原文（字符串），读音、意思、配音从课程里那一句来——所以必须一字不差。
- `towns` 13 个都要有（键是 `"0"`–`"12"`）；别的语言的 `units` 8 个都要有（键是单元 id）；英语只写 `towns` 和 `help`（课本单元是给学校学生的，已经有语法讲解）。
- `help` 的句子要进配音名单（整句，本机合成没问题）。

## 13. 分工（第二部分）

- **内容**（每门语言一个代理，含英语）：只写 `tools/course/<语言>/lessons.json`；可以在自己那门语言的 `review.md` 末尾记一笔（英语没有 review.md，就不记）。
- **界面**（第一部分那个代理做完第一部分接着做）：第 7–11 条；`tools/course/build.js` 把 `lessons.json` 并进 course.json 的 `LESSONS`（`help` 进 `VOICE`），英语的 `lessons.json` 生成 `lessons-en.js`（`window.LESSONS_EN`，也是 Node 模块，index.html 加载；`tools/voice/collect.js` 收 `help` 去配音）；`check.js` 查 `ex` 一字不差在这一课里、读音规矩；测试。
- **服务器**（主会话）：岛民的提示词加「求助的话照做」。
