## 自己读出来改掉的

1. 第 0 岛场景最后一句原来是「丽丽，再见！明天见！」：前面刚说过「早上好」，同一个早上说「明天见」不对，改成「王老师好！丽丽，我们是同学！」，顺带复现「同学」。
2. 楼层的英文：「在一楼」原来译成 "ground floor"，和「二楼」译成 "second floor" 用的是两套算法；统一成美式（一楼 first floor、二楼 second floor），和中文的数法一致，不会让学的人以为「二楼」是英式的 first floor。
3. 第 7 岛日期原来想用「五月二十号」：520 在网上是表白的谐音，给孩子用的课不碰，换成「五月十六号」。
4. 生日、家里几口人这类问题只让书里的人物问人物（「丽丽的生日是几月几号？」）；岛主的问题都改成不涉及个人信息的（「照片里有几个人？」「今天几月几号？」「你去过动物园吗？」）。
5. 所有本来要用「把」的意思都换成了不用「把」的自然说法（「我们收拾一下桌子吧」「请开一下窗户」「扔进垃圾桶里」），把字句留到 3 级第 1 单元。
6. 「他 / 她」读音完全一样（tā），对话的错误选项里不靠「他 / 她」区分对错（原来想用「她是我妈妈」当「他是谁？」的错误答案，听不出来，换掉了）。
7. 没用儿化：一律「哪里、一点、玩、有点」，不用「哪儿、一点儿、玩儿」。

## 拿不太准、请审稿的人看的

- **个**：数词后面写 `gè`（一个 yí gè、几个 jǐ gè、两个 liǎng gè），「这个 / 那个 / 哪个」写轻声 `ge`。口语里数词后的「个」也常读轻声，不少教材写 `yí ge`；选了本调是为了和「一」的变调 yí 对得上（变调按「个」的本调四声算）。
- **这里 / 那里 / 哪里** 写 `zhè lǐ / nà lǐ / nǎ lǐ`，方位后缀「书包里、教室里、河里」写轻声 `li`。词典里「这里、哪里」的「里」也标可读轻声，两种都对，选了教材里更常见的一种。
- **旁边 páng biān、后面 hòu miàn、外面 wài miàn**：都写了本调，口语常轻读（hòu mian），词典标「一般轻读」。
- **学生 xué sheng**：按《现代汉语词典》写轻声；很多教材写 xuésheng 或 xuéshēng。
- **聪明 cōng míng**：写了本调，词典标作可轻读（cōng ming）。
- **岛上 dǎo shang、床上 chuáng shang、天上 tiān shang、桌子上**：方位词「上」都写轻声；「上学、上课、上车、上星期」是本调 shàng。
- **谁** 写 `shéi`（口语常用读音），不写 `shuí`。
- **丽丽** 写 `Lì li`：叠字的名字第二个字口语里读得轻；也有人写 `Lìlì`。小明 `Xiǎo Míng`、王老师 `Wáng lǎo shī` 首字母大写。
- **啊**：「好啊」「好冷啊」都写 `a`。实际读音会跟着前一个字变（好啊 听起来像 hǎo wa、冷啊 像 lěng nga），拼音按规范不写变读，配音照真实读法就行。
- **哇 wā、嗨 hāi、哈哈 hā hā**：语气词按常见写法。
- **冰淇淋 bīng qí lín**：也写作「冰激凌 bīng jī líng」，两种都通行，选了更常见的。
- **贝壳 bèi ké**：「壳」口语读 ké，书面词里读 qiào（地壳），这里是 ké。
- **垃圾 lā jī**：普通话规范读音；有些地方读 lè sè，不用。
- **画画 huà huà**：北方口语常说「画画儿」，按不用儿化的原则写成两个本调。
- **英文意思不好写短的**：「爷爷 / 奶奶」写成 "grandpa (dad's side)" / "grandma (dad's side)"，英语没有区分父系母系的单词；「家」写成 "home, family"；「草地」"grass, lawn"；「排队」配的图 👥 不太像排队，看图说词时可能要换图或不出这个词的看图题。
- **教室** 的图用了 🧑‍🏫（老师在讲课），表情里没有「教室」，看图题可能和「老师」混；同一岛里没有「老师」这个词，不会撞，但跨岛复习时要注意。
- **「你好吗？」没有教**：这是教材常见、但母语者很少这样打招呼的说法，故意不用；问候只用「你好」「早上好」「王老师好」。
- **第 6 岛**「现在八点十分」：口语也说「八点十分」「八点过十分」，用了最通用的。
- **第 9 岛**「红灯停，绿灯行」是人人都会说的交通口诀，不是哪本教材的句子，保留了。
- **第 11 岛**错误选项「我会堆雪人」和正确答案「会，明天很冷」都用「会」（一个是本领、一个是将来可能），是故意的听力干扰，但对完全的初学者可能稍难。

### 改了什么（3 处）

1. 第 0 岛「同学」的图：👫 → 🏫。👫 是一男一女手牵手，孩子用的课里会被读成「情侣」；🏫 表示同校，不碰恋爱联想。
2. 第 7 岛「贺卡」的图：💌 → ✉️。💌 是情书，同上。
3. 第 8 岛场景「喜欢！猴子很聪明。」读音：`cōng míng` → `cōng ming`。《现代汉语词典》标 cōngming，口语里「明」读得很轻；和已经写成轻声的「学生 xué sheng、认识 rèn shi、意思 yì si」同一条规则。作者原先列为拿不准，我按规则改了。

### 没改、留给你判断的

- **看图说词的图**（都不是错，只是可能认不出来）：第 3 岛「教室」🧑‍🏫 画的是老师；第 9 岛「排队」👥 不像排队；第 12 岛「昨天」⏪ 要靠猜；第 0 岛「再见」🚶 只有走开的意思；第 2 岛「弟弟 / 妹妹 / 哥哥 / 姐姐」只能看出性别和大小，看不出长幼，这几个词最好别一起出看图题。
