# 让游戏认新语言（引擎第一步，2026-11-20）

前面已经有：课程包系统（`packs.js`，`tools/pack/SPEC.md`）、三门语言的打分和提示（`lang.js` + `lang-es/ja/zh.js`）、课程源文件和 `course.json` 的格式（`tools/course/SPEC.md` §6）。这一步把它们接进游戏：**选了西班牙语 / 日语 / 中文，就能用那门语言闯关、复习、看对话剧场、对战、在大地图上答题**，口语用那门语言识别和打分。

**英语一个字节都不许变**：现在的英语课（`course === 'en'`，包括老模式）走的每一条路照旧，现有 39 个测试不改就全过。新语言的路全在 `LANG`（不是英语时才有）后面。

## 1. 一门课一份存档

- 现在学哪门：`EchoPacks.course()`（`localStorage['echo-course']`，没有就是 `'en'`）。只有课程包模式才可能不是英语。
- 存档的键：英语还是 `echo-island-v1`；别的语言 `echo-island-v1@<语言>`。凡是从这个键派生的（`-bak1..3`、`-pos`、`-pre`、`-bad`、原生每天的备份文件名、导出文件名）都跟着走，各门课互不相干。不属于存档的（账号令牌、出错记录、画风开关、课程包地址）照旧共用。
- 第一次学一门新语言 = 新的存档：`fresh()` + 把现在这份存档的 `settings` 抄过去（界面语言、谁在学、学习锁、限时、音乐、画质、方向、操作方式、家长密码……；`track` 固定成 `'level'`，和课本有关的不抄）。怪兽、金币、进度不互通（老板知道）。
- 换语言：设置「📦 课程和语音包」里每门能学的课一行「学这门」→ 确认（孩子模式要家长密码）→ 这门课的 core 没装先装 → `EchoPacks.setCourse(lang)` → 重新打开页面。全新的开始在「选语言」那一步选。
- 能学的课 = 目录里有、`course: true`、`EchoLang.has(lang)`。中文课在中文界面里不列出来。

## 2. 启动时换内容

`EchoPacks.ready()` 好了以后（非英语课这时 `EchoPacks.content()` 是 `course.json` 的内容），`start()` 之前：
- `WORLDS` / `SCENES` / `BOOKS` 换成课程里的；game.js 的 `W` / `BK` / `NB` / `WX` 和交给 MonsterGame / EchoWorld / EchoTalk 的 `api.W` / `api.WX` 跟着换（它们现在是加载时定下的常量：改成能换的，英语不换）。
- `TALK_NPCS` 换成课程的 `TALK`（talk.js 加载时抓住的那份也要换）。
- `EchoLevels` 用课程的 `MAP`（加一个登记的口子，别在 levels.js 里写死每门语言）。
- 建一张「原文 → 条目」的表（所有词、句子、对话的每一句、小剧场的每一句），和 `EchoLang.lexicon(lang, content)` 的读音表：打分、提示、标读音都靠它们从一句话找回 `seg` / `r`。
- 课程内容读不出来（包被清了）：停在「下载课程」那一页，**不许拿英语内容配别的语言的存档往下走**。

## 3. `LANG`：凡是认定「在学英语」的地方

`const LANG = 课程不是英语 ? EchoLang.get(course) : null`。清单（位置是 2026-11-20 的行号，会漂）：

| 地方 | 英语（不动） | `LANG` 时 |
| --- | --- | --- |
| 打分 `scoreSpeech` / `bestScore` / `earlyMatch`（game.js ~2396） | 原样 | `LANG.score / best / early(target, heard, { entry, lex })` |
| `recognizeRaw` 的 `short`（~1989） | ≤ 2 个词 | `LANG.short(text, entry)` |
| 撤提示 `cueText`（~2736）、`onHint` 的梯子、monsters.js 遮字（~1055 / 1062） | 原样 | `LANG.cue(text, lv, entry, first)` |
| 排句子 `tokens`（~2461）、`onLoCheck` | 按空格 | `LANG.tiles` / `LANG.joinTiles` |
| 逐词标色 `wordsHTML`（~3211）和 marks | 按空格 | `LANG.pieces(text, entry)` |
| 意思 `meanOf` / i18n `gloss` | 界面是英语 → null | 目标语言是 `course`：英语界面给 `en` 那份，中文界面给中文；没有才 null |
| 朗读 `say()` | 原样 | 课程包里按原文的 key 找；没有 → 本机声音（`speechSynthesis`，挑 `LANG.tts.web` 的声音）；这一步不走云端合成 |
| 识别语言 | `en` / `en-US` | iPhone 本机识别 `LANG.asr.apple`（`LocalSpeech.swift` 的白名单加上 es-MX / es-ES / es-US / ja-JP / zh-CN）；浏览器识别 `LANG.asr.web`；云端识别带上 `LANG.asr.cloud`（服务器现在还写死英语，见 §6） |
| `nativeListen` 里按空格数词的地方（talk.js ~1375 / 1453） | 原样 | `LANG.head` / `LANG.countUnits` |
| 复习本 `free:` 的键、去重键 | 原样 | `LANG.key(text)` |
| 起名（story.js ~265、setup.js ~330、monsters.js 昵称 ~2247） | 原样 | 这一步不改规则（名字还是拉丁字母），只保证不出错 |

**读音**（日语、中文）：凡是把要学的那句话显示出来让人看、让人念的地方（题目卡片、选项、对战的咒语、对话剧场、大地图的说话任务），按词块标读音——用真的 `<ruby>`，`E.ruby(text)` 一个函数出 HTML（找得到条目就逐块标，找不到就原样）。遮起来的提示（凭记忆说）不标。设置里一项「读音：显示 / 不显示」，默认显示。西语没有这一项。

## 4. 这一步先关掉的（界面上说实话，不装作有）

非英语课里：
- **和岛民聊天、支线委托、AI 发音点评**：服务器的人设和提示词还只会英语。聊天页写「这门语言的 AI 聊天还在做」；学习锁里聊天那一项整天免（周报里看得到原因）；每日任务不出「和岛民聊天」；委托人头上没有「?」。
- **能力检测**：还没有题库。选完语言问「学过多少」，直接从 0 级（或自己选的级别）开始，结果页说明检测题在做。
- **今日目击**：线索是英语拼的，先不出。
- 课本那一套：「适用于沪教版词汇」的说法、按日期猜学到哪、销售版只开本学年——都只属于英语课；别的课所有单元都开放，叫「课程单元」。
- 挑战馆的单元门槛：课程的单元没那么多，要求的单元数不超过现有的。

## 5. 大地图和对战里写死的英语句子：台词翻译表（2026-11-21）

剧情台词、告示牌、对战喊话、回声技能的指令、拿到道具……是代码里的英语。`node tools/course/lines.js` 把它们收成 `tools/course/lines-src.json`（整句、模板、词），各门语言翻在 `tools/course/<语言>/lines.json`，`build.js` 并进 course.json 的 `LINES` / `LINES_T` / `TERMS`（格式 `SPEC.md` §8）。

**一个口子**：game.js 的 `lineOf(英语原文, { zh, fill, swap })`（交给各模块是 `E.lineOf`，页面上是 `EchoGame.lineOf`）→ `{ t, seg, r, en, zh, mean }` 或 null。查法是 packs.js 的纯函数 `EchoPacks._.lineFind`（整句 → 模板 → 单独一个词），模板里的怪兽名可以是起的昵称（照原样），`{name}` / `{rival}` 原文里有没有换都认。查到的那句登记进条目表 ENTRY——标读音、逐块标色、`LANG.score` 按 seg / r 打分、`say()` 都把它当课程内容。`mean` 是界面语言的意思（中文界面：页面上原来的中文；英语界面：英语原文），说到「英语 / English / 英文名」的换成在学的语言 / 「名字」（`courseWord`）。`say(英语)` 在别的课里自己查：有译文就念译文（课程包里有配音放配音，没有用本机声音），没有就不出声。

| 画面 | 有译文 | 没有译文（过渡办法） |
| --- | --- | --- |
| 对话框的一页（剧情、村民、旁白、告示牌 / 石碑、选择页、输入页：world.js `langPage`） | 正文是译文（日语 / 中文标读音、不逐字打出来），有 🔊；下面一行是界面语言的意思，按「剧情中文」的设置收成「译」，和英语课一样 | 正文是界面语言那份（中文界面 = 原来的中文；英语界面 = 英语原文，说到「英语」的换成这门语言），没有 🔊、没有「译」、不朗读 |
| 说话任务（`speak`：念通行证、选伙伴、孵蛋、回声技能的指令、村民教的句子） | 要说的是译文（带名字），按这门语言打分；上面那一行：台词本身就是要说的那句时是界面语言的说明（中文界面用这一页的中文，英语界面「Say it in …:」），不然是台词的译文；要说的那句下面：英语界面是英语原文 | 换成这座岛课程里的一句（按英语原文 / `lkey` 的哈希固定挑），题面给它的意思，进复习用课程的编号 |
| 选回答（`answer`） | 选项都有译文才换（问句有译文也换） | 选项是课程内容的照旧；不是的整页换成课程里的一段对话 |
| 选伙伴的贝壳（story.js `starterBag`） | 「打开哪个贝壳」「X 是 Y 系的，要它吗」是译文（属性名用翻好的词），下面是操作说明 / 意思 | 只显示界面语言那份 |
| 开场的照片、名字 | 照片下面不写英文小字；输入框的提示用 `.c` 版本：名字暂时只能用拉丁字母，不说「英文名」 | 同左 |
| 对战喊话、收服 / 进化的话（monsters.js 的 `E.say`） | 念译文（喊话的模板 × 怪兽名） | 不出声 |
| 对战里要说的（唤醒、收服念的句子、学招、起名、和怪兽说话）、选伙伴的那个弹窗 | `learnL(键, 岛, 英语原文, 中文)` → 有译文用译文 | 按键的哈希挑课程句子 |
| 手册介绍（`dexEn`，monsters.js `dexText`） | 译文（标读音）+ 🔊 + 意思 | 只显示界面语言那份 |
| 地名横幅 | 下面那行是翻好的地名，念的「Welcome to …!」是译文 | 英文地名 |
| 回忆挑战馆的翻牌（isles/e 的 `memWord`） | 词牌写这门语言的词；配成一对的那页正文是这个词（下面「配对成功！fue 就是“去了”。」，英语界面是英文原词），不用「went = 去了」那个模板；然后大声读这个词 | 词牌照旧是英文，读的那句走说话任务的过渡办法 |

「英语 → 在学的语言」的改写（`courseWord`）：英语界面里，原文本来就说到这门语言的（学科岛课程表上和 English 并列的学科 Chinese，学中文时翻成「语文」），先改成「Chinese (language arts)」再换 English，两门课的意思不会变成同一个名字。中文界面（学西语 / 日语）原文的学科写的是「语文」，不会撞。

对战的题（招式要念的词和句子、听音选）本来就从 `WX` 来，自然是新语言。`tests/course.test.js` 用 `lines: false` 生成课程（只测过渡办法），`tests/course-lines.test.js` 用 `tests/course-lines-fixture.js` 的小样测有译文的这些画面。

## 6. 这一步不做、要留好口子的

- 服务器（`cloud/`、`server/relay.js`）的识别语言、合成语言、聊天提示词：不改、不部署。云端模式下 iPhone 的本机识别用不了时，新语言的口语题按「AI 用不了」的现成出路走（先跳过、进复习）。
- 台词翻译表、能力检测题库、2–3 级单元、日语配音：内容那一路的事。
- 安卓销售版的课程包模式。

## 7. 测试

- `tests/course.test.js`（Playwright）：用真的课程源文件经 `tools/course/build.js` 出的 `course.json` + 几段假配音做成小样课程包（builder 还没好时先按 `tools/course/SPEC.md` §6 自己转一份，好了换成真的）。西语、日语、中文各走一遍：选课 → 新存档 → 每种题型（听音选义、听音选词、看图说、跟读、听句选意、排句子、对话选答、说回答、Boss）→ 假识别结果按 `EchoLang` 打分（对、错、半对各一例，和 `tests/lang.test.js` 的结论一致）→ 日语 / 中文有读音、西语没有 → 进每日复习 → 对战一回合 → 大地图一个说话任务换成了课程里的句子 → 换回英语，英语存档一个字没变。

- 改了 Swift（只有识别语言的白名单）：本机编不了，写清楚等云上模拟器。

## 8. 做的时候和上面不一样的地方、还要定的事（引擎这一路记的，2026-11-20）

和规格不一样的：
- **手机「下载/EchoIsland」里的每天备份**：别的课不写（`nativeBackup`）。文件名是原生按日期起的，分不出语言，同一天会把英语课那份盖掉；要分开得改原生（安卓 `BackupNames`、iPhone 同名的那份）。从那里恢复、导入文件时只认这门课的存档（存档里带 `course`，game.js 的 `mine()`；英语的存档没有这个字段）。导出的文件名带语言（`echo-save-es-日期.json`）。
- **全新开始选了别的语言**：「选语言」→「下载课程」→ 继续 = 换课、重新打开页面；打开以后能力检测从「谁在学」开始（「选语言」那一步还能返回去改）。
- **没有检测题时的级别**：「学过多少」的 0–3（刚开始 / 学过一点 / 能简单对话 / 比较自如）直接当第 0–3 级（「自己选的级别」），聊天级别一样；结果页、设置里那一页都能再调。§4 说的「从 0 级开始」只在选「刚开始」时是这样。
- **读音**按 seg 一整块标（`友だちの` 上面是 `ともだちの`，助词、送假名也在里面）；日语全是假名的块不标。除了 §3 列的地方，排句子的块、复习本列表、关卡预习、答完以后那一行也标。遮起来的提示不标。
- **界面上写着「英语」的句子**：i18n.js 加了 `variant('.c')`——别的课里键有 `.c` 版本就用它（`{lang}` = 语言名）。改了 26 句（题型标题、话筒提示、对战菜单、回声技能说明、小检查……；页脚、游戏说明、课程单元的标题另用了自己的键）。**没改的**：剧情台词本身说到英语的（「他们会教你英语！」「这些岛上的怪兽都听得懂英语」）、周报 / 学习锁里「用英语聊天」那几句（别的课里聊天关着，看不到大部分）、称号「英语船长」。
- **§5 的说话任务换掉以后**：正文换成一句说明「用{lang}说出来：」（原来的英语那句和换上的课程句子对不上，放着更糊涂），下面是课程句子和它的意思；选回答的页换成课程里的一段对话时，原来的图和说明（鹦鹉门的钟点）去掉；村民「看图选词」的问法换成「这个用{lang}怎么说？」。按什么挑：英语原文的哈希；带名字的模板用不带名字的键（`be my partner`、`learn a move`、`your name is`、`talk:第几句`、`wake up`、`skill:技能`），同一个地方每次是同一句。
- **`say()` 在别的课里只念课程内容**（条目表里有的、课程包里有配音的），别的（喊话、怪兽名、玩家名、商店店员）都是按长短停一下、不出声。
- **挑战馆门槛**：不只是「不超过现有的」，按现有单元数摊到 13 座岛：第 z 个岛主要 ceil((z+1) × min(16, 单元数) / 13) 个单元（现在 8 个单元：1、2、2、3、4、4、5、5、6、7、7、8、8）。
- **干扰项去重**：中文课的条目第 2 格（中文意思）是空的，别的课一律按界面语言里的意思去重（game.js `meanKey`、world.js 钓鱼、monsters.js `langDef`），不然中文课的听音选义、听句选意、钓鱼、对战防守只剩一个选项。
- 课程内容 15 秒还没读出来也停在「下载课程」页（IndexedDB 一直不回话的设备）。
- 台词翻译表（2026-11-21，§5）：和最初留的口子不一样——`LINES` 只放整句（键是英语原文，带 `{name}`），模板和词另外放（`LINES_T`、`TERMS`），游戏里现拼（`EchoPacks._.lineFind`），不把「模板 × 手册里每一只怪兽 × 招式」全展开进 course.json（日语展开要好几 MB）；英语能拼出来的每一句都对得上由 `tests/course-build.test.js` 展开核对。配音（`VOICE`）照样展开：翻好的整句（不带名字的）、对战喊话 × 每只怪兽（和英语配的那几种一样）、选伙伴、道具、地名；技能指令、和怪兽说话这些多半是昵称，用本机声音。`EchoPacks.line(英语原文)` 还在（不认昵称和玩家名字），游戏里用 game.js 的 `lineOf`。
- 自由变量的模板（剧情自己的小词表：蒂姆的家人、天气、音符……）靠翻译里的 `vals`；没给的，值本身是一句翻好的台词也行，不然整句走过渡办法。
- 说话任务的意思：中文界面没有「要说的那句」单独的中文意思（源码里只有提示语），上面那一行是这一页的中文（里面夹着的英语原句换成了译文）；英语界面下面是英语原文。

还要定 / 没验证的：
- 原生每天的备份要不要按语言分开（要改原生）。
- 「学过多少」→ 级别这样对应行不行。
- iPhone：Swift 白名单（`es-MX / es-ES / es-US / ja-JP / zh-CN`）本机编不了，等云上模拟器；`speechState` 还是按 en-US 报能不能用，这门语言手机上没有本机识别时 `speechStart` 回 unavailable → 网页按「AI 用不了」走（云端模式）或者改走云端识别（非云端模式）。真机上西语 / 日语 / 中文的识别准不准、本机声音（`speechSynthesis` 有没有这门语言的声音）都没试过。
