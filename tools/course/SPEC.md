# 课程内容怎么写（2026-11-20）

四门要学的语言：英语 `en`（已有）、西班牙语 `es`、日语 `ja`、中文（普通话）`zh`。这份说明管后面三门的源文件：放在 `tools/course/<语言>/`，由 `tools/course/build.js` 生成课程包里的 `course.json`（见 `tools/pack/SPEC.md`）。

学的人可能说中文，也可能只会英语，所以**每一条的意思都要写中文 `zh` 和英文 `en` 两份**（中文课例外：`zh` 那份就是原文，可以不写）。

## 0. 硬规矩

- **全部原创**。不抄任何教材、课程、App、考试的句子和词表顺序；不出现任何现成游戏 / 动画 / 影视的名字、角色、地名、道具、招式（`node tools/check-banned.js` 会查，写完自己跑一遍，单独一条命令、看退出码）。
- 给全年龄的人用，孩子也在用：不写恋爱、暴力、烟酒、赌博、宗教和政治立场、身材评价；不问个人信息（真名、学校、住址、电话）。
- 内容讲的是**游戏里这个世界**里的日常（小岛、学校、家人、朋友、动物、天气……），不要写具体国家的时事。
- 语言要地道、是母语者真的会说的话，不是从英语课硬翻过来的。每门语言按它自己的难易顺序排（比如日语先「です / ます」，西班牙语先 ser / estar / gustar，中文先「是 / 有 / 在」和量词）。
- 人名：西班牙语用常见的西语名（Ana、Luis、Sofía、Diego…），日语用常见的名（はると、さくら、ゆい、そうた…），中文用常见的名（小明、丽丽、王老师…）；游戏里已有的角色（岛主、回声博士、Amy 站长）名字不变，日语里写片假名、中文里写中文名。
- 西班牙语：拉美通用的说法，不用 vosotros，不用只有一个国家说的词。日语：敬体（です・ます）为主，3 级以后再加常体。中文：简体字、普通话。

## 1. 每一条怎么写

所有条目都是对象。公共字段：

| 字段 | 意思 |
| --- | --- |
| `t` | 要学的那句话 / 那个词（目标语言，照正常写法：日语该用汉字的用汉字，中文用汉字，西语带重音符号和 ¿¡） |
| `zh` / `en` | 中文意思、英文意思（词 ≤ 8 个汉字 / ≤ 4 个英文词；句子自然就行） |
| `r` | 读音。**日语、中文必须有，西语不写**。日语：平假名（外来语照片假名）；中文：带声调符号的拼音，音节之间空格（`nǐ hǎo`） |
| `seg` | 只有句子有：把 `t` 切成词块（排句子的题用）。日语、中文必须有，接起来要和 `t` 一字不差（标点跟在前一块后面）；西语不写（按空格切） |

句子的 `r` 是和 `seg` 一样多的一列，每块对应这块的读音：
```json
{ "t": "わたしは学生です。", "seg": ["わたしは", "学生", "です。"], "r": ["わたしは", "がくせい", "です"],
  "zh": "我是学生。", "en": "I am a student." }
{ "t": "我有一只猫。", "seg": ["我", "有", "一只", "猫。"], "r": ["wǒ", "yǒu", "yì zhī", "māo"],
  "zh": "", "en": "I have a cat." }
{ "t": "¿Cómo te llamas?", "zh": "你叫什么名字？", "en": "What is your name?" }
```
- 日语的词块按文节切（助词跟着前面的词：`わたしは`、`学校に`），每块 1–6 个字；中文按词切。
- 中文的拼音写实际读出来的声调（一、不的变调照读音写：`yì zhī`、`bú shì`；三声连读照本调写）。

```json
{ "i": 0, "t": "目标语言的岛名（两三个词）",
  "boss": { "t": "岛主出场说的两三句话（用这一岛的句型，最后一句是问学的人的问题）", "r": "…", "zh": "…", "en": "…" },
  "words": [ { "t": "…", "r": "…", "zh": "…", "en": "…", "pic": "👋" }, … 12 个 ],
  "sents": [ … 8 句 ],
  "dlgs":  [ { "q": { "t": "问的话", "r": …, "seg": …, "zh": "…", "en": "…" },
               "a": { "t": "对的回答", … },
               "wrong": [ { "t": "答非所问的一句", … }, { … } ] }, … 6 段 ],
  "scene": { "cast": [["名字", "👧", "f"], ["名字", "👦", "m"]],
             "lines": [ { "who": 0, "t": "…", "r": …, "zh": "…", "en": "…" }, … 8–10 句 ] } }
```
- `words`：12 个，每个一个表情图 `pic`，一岛之内图不重复、意思不重复；尽量挑画得出来的词（看图说词的题要用）。
- `sents`：8 句，3–9 个词（日语、中文 2–7 个词块），都用得上这一岛的词。
- `dlgs`：6 段一问一答；`wrong` 两句是这一岛别的话，语法没错、只是答非所问，不能和对的回答意思一样。问句和答句都照「每一条怎么写」带齐 `r`、`seg`、`zh`、`en`（`wrong` 也要）。
- `scene`：两个人的一小段对话动画，8–10 句，把这一岛的句子串起来。
- `boss` 的名字不用写（游戏里已有），只写 TA 说的话。

## 6. 生成 `course.json`（`node tools/course/build.js <语言>`）

游戏里的代码读的是和英语一样的数组格式（`data.js` 的 `WORLDS` / `SCENES`、`book.js` 的 `BOOKS`），所以 `course.json` 就是「另一门语言的这几样东西」，多出来的读音、词块、英文意思放在每条最后那个对象里（game.js 的 `meanOf` 本来就读它）：

```json
{ "fmt": 1, "lang": "ja", "name": { "zh": "日语", "en": "Japanese", "self": "日本語" },
  "WORLDS": [ { "name": "你好岛", "en": "あいさつの島", "icon": "👋", "color": "#…",
      "boss": { "emoji": "🦜", "name": "鹦鹉船长", "en": "Captain Polly", "hello": "こんにちは！…", "x": { "r": "…", "zh": "…", "en": "…" } },
      "words": [ ["名前", "名字", "🏷️", { "en": "name", "r": "なまえ" }], … ],
      "sents": [ ["お名前は何ですか？", "你叫什么名字？", { "en": "What is your name?", "seg": ["お名前は","何","ですか？"], "r": ["おなまえは","なん","ですか"] }], … ],

```
- 小镇的中文岛名、图标、颜色、岛主的表情和名字照 `data.js` 第 i 个岛的（岛还是那座岛）；目标语言的岛名是源文件的 `t`。
- 中文课的 `zh` 是空的：条目第 2 格放空字符串。
- 大纲里有、还没写的册不进 `BOOKS`（先有 1 级就只出 1 级）。
- `VOICE`：这门课里所有要提前配音的句子（词、句子、对话的问 / 答 / 错的选项、小剧场每一句、岛主的话、聊天开场白），`g` 和英语的规矩一样（词和句子女声、对话和岛主两种、小剧场按角色的性别），`p` 是先后（小镇在前、按岛，再按册、按单元）。**配音念的是 `t` 原文，不是读音 `r`**（日语的「は」念 wa 靠原文）。
- 同一份输入生成的文件逐字节一样。`--check` 只检查不写。输出到 `dist/course/<语言>/course.json`（不进仓库）。

## 7. 配音和打包

- `tools/voice/gen.py --lang <语言> --lines dist/course/<语言>/course.json --out dist/voice/<语言>`：本机 Kokoro（英语照旧，默认参数不变）。西语 `lang_code='e'`、中文 `'z'`、日语 `'j'`；声音用 Kokoro 自带的那门语言的男女声各一个。key 还是 `tools/voice/key.js` 的哈希（对目标语言的原文算）。
- `node tools/pack/build.js --lang <语言> --course dist/course/<语言>/course.json --voice dist/voice/<语言>` 出课程包（`course.json` 标 core，配音照 `p` 排）。
- 合成完要抽查听得清不清：每门语言抽 60 段以上，用本机的识别模型转成字，和原文比（西语按词、日语和中文用 `lang-*.js` 的 `score()`），把通过率和没过的句子列出来。**对不上的不要硬收**：读错的（多音字、数字、外来语）换个写法重新合成，或者记下来。


`node tools/course/check.js <语言>`：字段齐不齐、个数、重复、`seg` 接起来等不等于 `t`、`r` 和 `seg` 一样多、日语读音里有没有混进汉字、拼音有没有声调、西语倒问号感叹号成对、图重复、意思重复、禁用词。**有一条不过就不算写完。**

另外每门语言写完要找一个没看过稿子的人（另一个代理）从头读一遍：有没有不地道、有错、超出这一级的，改完记在 `tools/course/<语言>/review.md`。日语和西班牙语对外卖之前还要找母语的人看（老板知道）。

## 8. 台词翻译表（`tools/course/<语言>/lines.json`）

剧情台词、告示牌、说话任务、对战喊话、回声技能的指令、拿到道具……这些在英语课里是**代码里写死的英语**（课程内容以外）。别的课里它们要显示成、念成在学的这门语言，下面一行是界面语言的意思（和英语课「英文 + 中文」一样的排法），要开口说的就照着翻好的这句打分。

### 8.1 原文：`tools/course/lines-src.json`（生成的，不要手改）

`node tools/course/lines.js` 从 story.js、world.js、monsters.js、game.js、setup.js、isles/*.js、dex.js 收出来（`--check` 只核对是不是最新的）。三样东西：

| 部分 | 每一条 | 说明 |
| --- | --- | --- |
| `lines` | `{ id, en, zh?, src, also?, kind, who?, g, vars? }` | 一句一条（同一句英语只有一条）。`zh` 是源码里挨着它的中文意思（翻译时看语境用，有的是提示语、不完全是意思）；`kind`：`say` 对话 / 旁白、`sign` 告示牌 / 石碑、`speak` **要学的人开口说的**、`ask` 选回答的题里问的话、`opt` 选项（要选、再说出来）、`ui` 画面上的字（选伙伴、手册介绍）；`who` 谁说的（`{name}` 是玩家，`{rival}` 是对手）；`g` 配音的声音；`vars` 句子里的 `{name}` / `{rival}`（游戏里换成玩家 / 对手的名字） |
| `templates` | `{ id, en, zh?, slots, expr?, an?, src, at?, kind, who?, g, dom? }` | 代码里拼出来的句子：`en` 里的 `{mon}` `{move}` `{item}`… 是空（slot），`slots` 写每个空是哪一类词。`an: true`：英语里 `a` 跟着后面的词变成 `an`（翻译不用管）。`dom`：生成配音时拼哪些（`starter` 选伙伴的三只、`learnset` 怪兽 × 学得会的招式、`evo` 进化前后、`{ types }` 这些属性的怪兽） |
| `terms` | `monster` / `move` / `item` / `place` / `skill` / `crystal` / `type` / `person` / `sign` / `ui` 各一列 `{ id, en, zh?, note? }` | 空里填的词：怪兽、招式、道具、地名、回声技能、水晶、属性（选伙伴时说的 fire / water / grass / electric）；后三类是画面上的名字和字（见下面）。每个词只翻一次 |

空的类别：上面七类词；`num` 数字、`name` 人名、`content` 课程内容本身（已经是这门语言）——这三类照原样填进去，不用翻；`free` 这一段剧情自己的一小撮词（`expr` 是源码里的表达式，`at` 是文件和行号，去那里看有哪些值）。

**画面上的名字和字**（2026-11-21 第二批，`terms` 里多三类，每条 `{ id, en, zh?, note }`，`note` 写它在哪儿出现、是谁）。这三类不进模板，是游戏里直接拿来显示的：
- `person`：对话框上的名字牌、对战顶上的训练师 / 岛主名字——说话的人、地图上的村民 / 训练师、岛主、擂主、嘘声团，还有说话的东西（Blackboard、Radio、Memory Door……）。`zh` 是源码里有的中文名（岛主、回声博士、小凯……）。翻成这门语言里这个角色叫的名字：人名照那门语言的写法（日语片假名、中文汉字；西语一般照原样，头衔要翻：Professor Echo → Profesora Echo），头衔 + 名字的（Fisher Bob、Student Amy）头衔翻、名字照写。
- `sign`：地图上画的字——房子门上的招牌（REST STOP / SHOP / GYM，新老画风和 2D 都画）、挑战馆地板格子上的字（教室名、学科、音符、回忆牌）、对话动画背景上画的字（cartoon.js）。英语全大写的翻的时候也可以全大写（西语 TIENDA），日语 / 中文照常写；招牌地方小，越短越好。前面的 ✓ 之类的记号不用管（游戏自己加回去）。
- `ui`：中文界面里「中文 + 英语」并排写的按钮上的那个英语词（是 YES / 不 NO、先不 Not now、出发 Let's go!……）。游戏里显示成「界面语言的那个词 + 这门语言的这个词」（中文界面「是 Sí」，英语界面「Sí (Yes)」），所以只翻英语那半，短。
- 怪兽、招式、道具、回声技能、水晶、地名在对战、手册、队伍、背包、商店、横幅上也直接用上面的 `monster` / `move` / `item` / `skill` / `crystal` / `place`（和模板里用的是同一份）。属性名（火、水……）、等级 Lv、VS、HP / 攻击这类是界面文字，不在这里。
- 日语、中文每个词都带 `r`（一个字符串）；地方够的地方（名字牌、招式按钮、手册标题、背包）显示读音，招牌和地板字不标。没翻的词游戏里照英文原样显示。

### 8.2 翻译：`tools/course/<语言>/lines.json`

```json
{ "lang": "ja",
  "lines": {
    "l1ko8nbm": { "t": "お名前を書いてね。", "seg": ["お名前を", "書いてね。"], "r": ["おなまえを", "かいてね"] },
    "l1pk8lj":  { "t": "わたしの名前は{name}です。", "seg": ["わたしの", "名前は", "{name}", "です。"], "r": ["わたしの", "なまえは", "{name}", "です"] } },
  "templates": {
    "t1vlru3u": { "t": "{mon}、きみの番だ！", "seg": ["{mon}、", "きみの", "番だ！"], "r": ["{mon}", "きみの", "ばんだ"] },
    "t1v41aln": { "t": "すみません、ティムの{x1}ですか？", "seg": ["すみません、", "ティムの", "{x1}", "ですか？"], "r": ["すみません", "てぃむの", "{x1}", "ですか"],
                  "vals": { "x1": { "mom": { "t": "お母さん", "r": "おかあさん" }, "dad": { "t": "お父さん", "r": "おとうさん" } } } } },
  "terms": {
    "monster": { "sprouty": { "t": "メブキ", "r": "めぶき" } },
    "item":    { "potion": { "t": "くすり", "r": "くすり" } },
    "place":   { "t0": { "t": "ハロー島", "r": "はろーじま" } } } }
```
```json
{ "lang": "es",
  "lines": { "l1ko8nbm": "Ahora escribe tu nombre.", "l1pk8lj": "Me llamo {name}." },
  "templates": { "t1vlru3u": "¡{mon}, te toca!", "tol0mr": { "t": "¡Encontraste un {item}!", "f": "¡Encontraste una {item}!" } },
  "terms": { "item": { "potion": { "t": "poción", "g": "f" } }, "monster": { "sprouty": "Sprouty" } } }
```

- 键是 lines-src.json 里的 `id`（`lines` / `templates`）和词的 `id`（`terms.<类别>`）。没翻的就不写（游戏里按 ENGINE.md §5 的过渡办法：只给人看的显示界面语言，要说的换成课程句子）。
- 值：西语可以直接写字符串（= `{ "t": … }`）；日语、中文要写对象，带 `seg`、`r`，照 §1 的规矩（`seg` 接起来和 `t` 一字不差，标点跟在前一块后面；`r` 和 `seg` 一样多；日语读音是平假名（外来语照片假名）、不许有汉字；中文是带声调的拼音、音节之间空格）。
- `{name}` `{rival}` 原样留在句子里，一个都不能少、不能多；模板里 `slots` 列的每个空（`{mon}` `{x1}`…）也要**正好出现一次**。日语、中文里一个空（或 `{name}`）自己是一块（后面可以跟标点：`"{mon}、"`），这一块的 `r` 就写那个空本身（`"{mon}"`），游戏里换成词的读音。
- 词（`terms`）：西语字符串或 `{ t, g? }`；日语、中文 `{ t, r }`（`r` 一个字符串：这个词的读音，片假名的名字读音可以和 `t` 一样）。怪兽名可以照英文不翻（专有名词）；**没写的怪兽名游戏里照英文原样填**，别的类别没写的话用到它的模板就当没翻。
- `free` 的空：在这个模板里写 `vals: { 空: { 英文值: 译文 } }`（值和词一样写法）。没写 `vals` 的，游戏里先看这个英文值本身是不是一句翻好的台词（lines 里有，比如剧情自己的问答选项），都不是就当这句没翻。
- **西语的性和数**：先想办法写成不跟词变的说法（`¡Conseguiste: {item}!`、`{mon}, ¡usa {move}!`）。实在要变的：词写 `g: "f"`（阴性；不写算阳性），模板另写一个 `f`（阴性的那一句，`t` 是阳性的）；一个模板里看第一个有 `g` 的空。复数（商店「`{n} {item}s`」这种）不按数变，写成不用变的说法（`Aquí tienes: {item} ×{n}.`）。
- 说到 **English / 英语** 的台词（「他们会教你英语」「这些怪兽听得懂英语」「英文名」），翻成在学的这门语言（或者去掉），游戏会把下面那行意思里的「英语 / English」也换成这门语言的名字；`{name}` 起名那句：名字现在只能用拉丁字母，别写「英文名」。
- **这句自己的意思（可选，2026-11-21 第三批）**：整句（`lines`，不是模板）可以多写 `zh` / `en`，是这句译文在中文界面 / 英语界面下面那行的意思。只在译文改写过、原来的意思对不上时写（讲英语语法、英语读音的句子：原文「Thirteen and thirty sound different. Listen for "-teen"!」、中文意思「thirteen 和 thirty 听起来不一样，注意听 “-teen”！」，译成「Trece y treinta suenan diferente. ¡Escucha bien!」以后，原来的意思就不对了）。不写的话游戏用原来的意思，里面夹着的英语自己换成译文（整句、引号里一一对应的、名字）；换完还剩英语单词的那句意思**不显示**（ENGINE.md §5）。`zh` 要写中文、`en` 里不能有中文，`{name}` / `{rival}` 和原文一样多。例：`"lf69mnv": { "t": "Trece y treinta suenan diferente. ¡Escucha bien!", "zh": "十三和三十听起来不一样，要听清楚！" }`。
- 要开口说的（`kind: "speak"`、`ask`、`opt`）：短、自然、这一级能说出口；同一个问答里对的回答和错的选项意思不能一样。
- 不能出现的词（`tools/banned-terms.txt`）照样查（`node tools/check-banned.js` 会扫这个文件）。

### 8.3 检查和生成

- `node tools/course/check.js <语言>`（`--lines <文件>` 只查一份翻译表）：有 lines.json 就一起查——`{name}` / `{rival}` 和模板的空一个不少、`seg` 接起来等于 `t`、`r` 和 `seg` 对齐（空那一块的 `r` 是空本身）、读音（同 §1）、`vals` 只给 `free` 的空、`zh` / `en`（这句的意思）只给整句（zh 写中文、en 没有中文、占位符和原文一样多）、日语 / 中文里没有剩下的英文词（原文里大写开头的专有名词除外）、西语里没有剩下的英语虚词（the / you / your / is / and…）、和英语原文一模一样的西语句子。**只提醒、不算错的**：没翻的（按 kind 数）、lines-src.json 里已经没有的 id（原文改了或删了，生成时不带它）、和英语一样的一个词（音符 Sol、人名）。
- `node tools/course/build.js <语言>`：有 lines.json 就往 course.json 里加三样：
  - `LINES`：`{ 英语原文: 译文 }`（原文就是游戏里 lines-src.json 的 `en`，带 `{name}` / `{rival}`）；译文西语是字符串（写了 `g` / `zh` / `en` 时是对象），日语 / 中文是 `{ t, seg, r, zh?, en? }`；
  - `LINES_T`：模板 `[ { en, t, seg?, r?, s: { 空: 类别 }, an?, f?, vals? } ]`（按字面长短排好，越具体的越靠前）；
  - `TERMS`：`{ 类别: { 英文词: 译文（同 terms 的写法） } }`。西语没写的人名（`person`）照英文填上（和英文一样的名字不写是西语译者的约定，lines-glossary.md；游戏靠它认出提示、意思里的「Kai」「Sam」是人名）。
  游戏里（packs.js 的 `lineFind`）先按原文整句找，找不到再一个个模板对：怪兽名可以是起的昵称（照原样）、`num` / `name` / `content` 照原样。英语游戏能拼出来的每一句都对得上（`tests/course-build.test.js` 把模板 × 词展开一遍核对）。
  - `VOICE` 里加上翻好的台词（不带 `{name}` / `{rival}` 的）、模板按 `dom` 展开的每一句、单独念的词（怪兽名、地名）；`g` 照 lines-src.json，`p`：小镇的课程内容 → 开场和第 1 组岛的剧情、选伙伴 → 课本 → 别的岛的剧情 → 对战喊话（按手册编号）→ 手册介绍。
