# 一步一步学：给完全零基础的人（2026-11-24）

老板 2026-11-24：「我觉得完全没基础的情况下有点难学，你来定个方案，可以让人真的从 0 开始学。」

## 现在为什么难（按零基础的人走一遍第一岛）

- 一次 12 个新词：单词卡翻一遍，马上从 12 个里随机考 10 题（四选一），错 3 次就失败。
- 第 2 关就要「看图自己说出来」，还按发音打分。
- 句子是整句硬记：`What's your name?` 里的 what、your、is 都不在单词表里，没教过，点上去也查不到意思。
- 一个词在一关里只出现一次，错了只扣心，不重新教。
- 冒险里的对话、和岛民聊天，零基础听不懂。

## 方案

原来的 7 关、冒险、聊天都留着，变成学完以后的巩固。前面加一条「一步一步学」的路：

1. **小步**：每节小课只学 3 个新词，约 3 分钟。一座岛 12 个词拆成 4 节。
2. **先教后练，由易到难**：看图听音认识 → 两个里选 → 三个里选 → 看意思选词 → 跟着读。同一个词一节里出现 5、6 次。
3. **错了不罚**：小课没有红心。答错马上亮出答案、再念一遍，过两题再问一次（同一题最多再问两次）。
4. **每节开头复习上一节的词**；一座岛的小课学完，再去闯原来的 7 关。
5. **句子拆开学**：每句话下面一词一词标意思，句子里每个词都点得出意思；先填一个空，再排句子，再跟读。
6. **开口慢慢来**：小课里只有跟读（有示范、分数照实显示），两次没读准就先往下走，不记错题；「不看字说」留在原来的关卡里。
7. **聊天给零基础的人「照着说」**：屏幕上给一句能说的话和意思；学完第一岛再引去冒险。
8. **日语假名、中文拼音**：一节 5 个，和单词穿插着学（现在的发音入门只是一张表）。

谁会看到：能力检测 / 「学过多少」是 0 级的人默认开；别的人在设置「一步一步学」里打开。家庭版的老存档没有检测结果，不受影响。

## 先后

## 第一步的规格（game.js「一步一步学」那一段）

- 开关 `S.settings.starter`：true 开、false 关、没有 = `S.place.lv === 0` 时开（自动化测试的浏览器里没写就当关着，和单词卡一样）。`starterOn()`。
- 进度 `S.mini = { n: { 小镇 / 单元编号: 学完几节 }, skip: { 编号: 1 } }`（skip：说了「我学过了，直接闯关」）。
- 分节 `miniGroups(wi)`：这一课的 words 按顺序 3 个一节；最后剩 1 个就并进上一节（13 个词 = 3 + 3 + 3 + 4）。
- 一节的步骤 `buildMini(wi, k)`（3 个词的一节 17 步，有上一节的 19 步；一个新词出现 5、6 次）：
  1. 热身：上一节的词，听音选意思 2 题（第一节没有）。
  2. 一个一个教：教学卡 `tc`（图、词、读音、罗马字、意思，自动念一遍，有 🔊 🐢）→ 马上认一次（听音选意思：第 1 个词两个里选，另一个是上一节的词；后面的在这一节教过的词里选）。
  3. 混着来：听音选意思（这一节的词当选项；最后教的那个刚问过，不再问）→ 看意思选词 `mw`（题面是图和意思，不先念，选完再念）→ 跟读 `sr_w`。
  4. 小测：这一节的词每个再听一次，选项里混着上一节的词（最多 4 个选项）。
- 规矩：没有红心（右上角是「🌱 第几节 / 共几节」）；选错了不记错题、不进复习，过两题再问一次（`miniAgain`），同一题最多再问两次；跟读两次没到 60 分（或两次没听清，`sayMax()`）就亮出答案往下走，不记错题；分数照实显示。每日任务照常算（听、说的次数）。
- 小课借闯关的画面：`P.mini = { k, n }`、题目带 `q.mini`；`good()` / `bad()` / `failSpeak()` / `onSkip()` / `finish()` 开头各有小课的分支，别的照闯关那一套走。
- 学完一节（`miniFinish`）：`S.mini.n[编号]` 加一；这座岛学过的小课里的词、还不在复习本里的，按「新学的」进每日复习（第 1 格、明天到期，占每天新进的名额——一天学完 4 节是 12 个词，当天只进 10 个，剩下的下次学这座岛的小课时补上）；经验 + 金币；算今天打卡；`dayLog().mini` 加一。结算页：这一节的词一个词一个小牌子（点一下念一遍）。
- 一座岛的小课都学完：记 `S.seenCards[编号]`（第 1 关不再先弹单词卡），结果页的主按钮是「开始闯关」。
- 入口：小镇 / 单元卡片上一排「🌱 一步一步学 ① ② ③ ④」（开着、或者学过至少一节才显示；只能点学过的和下一节）；开着时点第 1 关先问「先一步一步学」（开始小课 / 我学过了，直接闯关）；新手路线里「用单词卡认识这一课的词」换成「上小课」；第一节之前先看「这一课学什么」（没看过的话）。
- 测试 `node tests/starter.test.js`（英语课：入口、步骤、规矩、结算、四节学完、跳过、设置、新手路线、英语界面、横屏；截图 `starter-*.png`）；`tests/words.test.js` 的 ja / zh / es 各有一段小课（教学卡的读音、罗马字、意思、课程包里的配音；截图 `words-<语言>-mini-*.png`）。

## 2026-11-24 晚：对话题写上意思（第二步里先做了的一小块）

老板在西语课的「听问选答」里：「是不是写一下翻译比较好，我是纯初学者，难度不小呢」。这类题（听问选答 `lr`、说出回答 `sr_d`、BOSS `bt`）从头到尾没有一句意思。
别的课的课程内容里问句、答句、错误选项都带着 zh / en（`tools/course/<语言>/` 的 dlgs），以前没显示。现在（game.js 的 `dlgMean`）：

- 听问选答、BOSS：答之前不显示（还是先靠耳朵）；答完，问句下面、每个选项下面、下面那一条里都亮出意思。
- 听问选答多一个「看意思」：没答之前想看就点，问句和选项的意思一起亮出来，算带提示（经验减半，和「看原文」一样）。
- 说出回答：对方那句话下面、要说的那句下面直接写着意思（要说的那句本来就给看原文）。
- **英语课的对话没有中文意思**（data.js / book.js 的 dlgs 只有问、答、错误选项三样）：`dlgMean` 给 null，画面和以前一样。要补得写内容（13 座岛 × 6–7 段 + 46 个课本单元 × 12 段，每段四句）。

## 没做的、要知道的

- 默认开只看 `S.place.lv === 0`；自动化测试的浏览器里没写 `settings.starter` 就当关着（所以「默认开」这一条只有人手点过，没有自动测试）。
- 细节检查（`tools/ui-audit/screens.js`）里还没加小课的画面。
- 小课里做到一半退出不记进度（下次从这一节的头开始）。
- 结算页出来 1.7 秒以后才弹「升级了」，这时已经点了「下一节」的话会盖在下一节上面（闯关的结算页也这样）。
- 第二步（句子小课）开工前先定「一词一词的意思」放在哪：别的课放 `tools/course/<语言>/` 的源文件、并进 course.json；英语课和 `lessons-en.js` 一样另出一个生成的文件。
