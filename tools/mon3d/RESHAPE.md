# 把「纸片一样扁」的怪兽重新做成立体的（2026-11-24）

老板 2026-11-24：「现在开始来完善这些怪物的那些模型，因为现在还是像纸片人一样。」

## 查出来的情况

- 386 只里 18 只没有模型（`hold.txt`，对战里是一张朝着镜头的原画），约 50 只的模型是一张薄片：从背后看还是一张脸、侧过来只有一条线。
- 一上来就会遇到的几只正好都在里面（雨滴滴 #4、小熔岩 #14、雾团 #17、小贝壳 #26、水花花 #31）。
- **原因**：原画是正面、平涂、没有明暗的卡通画，Hunyuan3D 的「形状」那一步看不出厚度。换种子没用——雨滴滴试了 6 个种子，厚度比最好 0.23；水花花 6 个里 5 个是 0.01（真的一张纸）。
- 以前的补救是绑骨骼时写 `thick`（沿左右方向硬拉厚）。试过把现成的薄片沿前后拉厚 3 倍：变成一本带脸的厚书，不能用。
- iPhone 的内核（WebKit）读得出发布的模型（带骨骼的那种），不是「没加载出来」。

## 做法：先给原画补出立体的明暗，再生成形状

`tools/mon3d/puff.py`：按轮廓把原画「吹鼓」——在轮廓里解一遍「吹气球」（泊松方程，边上是 0、里面往上鼓，出来是光滑的鼓包），算出法线，打一盏左上方的灯，边上压暗、鼓的地方提亮。颜色还是原画的颜色，看着像一个鼓鼓的玩具。

- **形状**用补了明暗的图生成（`gen.py --src=puff --notex --pca`）；
- **贴图**还是用原画（`gen.py --noshape --src=src1`），所以颜色、花纹和原来一样。

效果（厚度比 = 顶点主成分最薄 / 最长）：雨滴滴 0.23 → 0.55，小熔岩 0.18 → 0.59，都是第一个种子就成。带大鱼鳍的水花花不行（0.01 / 0.02 / 0.14），要另想办法（见下面「没做的」）。

## 怎么量扁不扁

`D:/Claude/tools/hy3d/Scripts/python tools/mon3d/flatscan.py --dir=art/mon3d --suffix=.glb`：顶点主成分三个方向 a ≥ b ≥ c，
`paper = c / b`（最薄比中间）——纸片这个数很小，蛇、龙这种细长的不会被冤枉。2026-11-24 量绑好骨骼的母版：< 0.2 有 8 只、0.2–0.3 有 17 只、0.3–0.4 有 26 只、≥ 0.5 有 262 只。
这一轮重做的是 `hold.txt` 的 18 只 + `paper < 0.35` 的 33 只（一共 51 只，按手册编号排，越早遇到越先做）。

## 一步步

```bash
# ① 形状 + 贴图（显卡，一只 3–6 分钟；不动现成的 _raw.glb，不绑骨骼，不发布）
bash tools/mon3d/reshape.sh p1 <id> [id ...]
#   结果 art/hy3d/reshape-p1.txt：每只一行「id 厚度 种子 ok / flat」；ok 的有 art/hy3d/<id>_raw_p1.glb
#   换种子 / 明暗重一点：SEEDS=7,1,3 K=1.6 bash tools/mon3d/reshape.sh p2 <id> ...

# ② 换上去（旧的留一份）、绑骨骼、看检查图
cp art/hy3d/<id>_raw.glb art/hy3d/<id>_raw_flat.glb      # 第一次才留
cp art/hy3d/<id>_raw_p1.glb art/hy3d/<id>_raw.glb
bash tools/mon3d/rigtool.sh rig <id>                     # 读 tools/mon3d/rigs/<id>.json → art/mon3d/<id>.glb + art/mon3d/check/<id>.png
#   形状是照同一张原画生成的，正面的轮廓差不多，原来的骨骼多半还能用；检查图里手脚被拉长、身体撕开的，照 RIGGING.md 改关节。
#   原来靠 "thick" 硬拉厚的，新模型已经够厚了：把 "thick" 删掉。没有骨骼文件的（原来没绑过）照 RIGGING.md 新写。

# ③ 发布、对比、放进真的对战里看
node tools/mon3d/publish.js <id> [id ...]
node tools/mon3d/vdiff.js --a <旧的发布版目录> --b assets/mon3d --ids <id,…> --sheet-ids <id,…> --views me:idle,foe:idle,front:idle --label reshape
node tools/mon3d/fxcheck.js --pairs <id>:<id>
#   原来在 hold.txt 里的：发布以后从 hold.txt 删掉（游戏就不再用纸片）；regen.txt 里的也删掉
```

旧的发布版从 git 里取：`git show HEAD:assets/mon3d/<id>.glb > <目录>/<id>.glb`。

## 验收（每只都要看图，不能只看数）

- 厚度比 ≥ 0.40（`reshape.sh` 的及格线）；
- 对比图里从背后看（`me:idle`）不再是一张脸；
- 检查图四个动作（待机、走路、攻击、倒下）手脚不拉长、不撕裂；
- `fxcheck.js` 没有报错。

## 没做的、要知道的

- **带大鳍、大翅膀的（水花花这种）补了明暗还是薄。** 可以再试：明暗重一点（`K=1.6`）、别的种子、把鳍从图上先去掉再生成。还不行就得给它画侧面 / 背面的图，用多视角的模型（Hunyuan3D-2mv，本机没有，下载要先问老板）。
- 贴图那一步有时在肚子、背上留一道接缝（雨滴滴正面有一小块），没处理。
- 改动只在对战和新画风的大地图里看得到；手册、队伍里一直是 2D 图标。
- 这是「形状」的事。所有怪兽的贴图都带着原画的黑边和平涂，打光也偏平，看着像贴纸——这一条还没动（另一件事：改材质，让明暗分得更开、加一圈边缘光）。
