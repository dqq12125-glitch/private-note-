# 给怪兽 3D 模型标骨骼（子代理用的说明）

流水线：Gemini 图 → Hunyuan3D 生成 `art/hy3d/<id>_raw.glb` → **你在这里标关节** → `tools/blender/monrig.py` 自动算权重、做 idle/walk/attack/hit/faint 五个动作 → `art/mon3d/<id>.glb`。

你只写 `tools/mon3d/rigs/<id>.json`，不要改任何代码文件。

## 步骤（每只）

1. `bash tools/mon3d/rigtool.sh grid <id>` → 看 `art/hy3d/grid/<id>.png`（左：正面，横轴 x；右：侧面，横轴 y，右边是背后；纵轴 z，0.1 一格）。模型已归一化：脚底 z=0，身高 1。
2. **定朝向 yaw**（度，绕竖轴转）：目标是**脸朝 -Y**（也就是左图"正面"里看得到脸）。
   - 正面图里是脸 → `yaw: 0`（常见）
   - 正面图里是侧脸、嘴/鼻子朝图的右边（+x）→ `yaw: -90`；朝左（-x）→ `yaw: 90`
   - 斜着（3/4 侧面）→ ±45（朝右 -45，朝左 45）；看到的是后脑勺 → 180
   - yaw 不是 0 时，用 `bash tools/mon3d/rigtool.sh grid <id> <yaw>` 重渲一遍，**关节坐标一律按摆正后的新图量**。
3. **太扁**：摆正后左右（x 方向）宽度不到 0.25 的，加 `thick`（1.3–2.2）把它加厚，同样重渲 `grid <id> <yaw> <thick>` 再量。
4. **会飘的**（鱼、幽灵、气球、浮空的传说）加 `"fly": true`。
4b. **脚下连着一块薄地面圆盘/底板**的：加 `"cutbase": 0.02`（删掉所有顶点都低于 0.02 的面，底板就没了；底板厚一点可以用 0.03–0.04，别超过脚踝）。跑完看检查图确认底板没了、脚还在。
5. 写骨骼。格式：`[名字, 父骨骼或null, [起点x,y,z], [终点x,y,z]]`，起点是关节，终点指向末梢。骨骼要在身体里面。
6. `bash tools/mon3d/rigtool.sh rig <id>` → 看 `art/mon3d/check/<id>.png`（4 张：待机、走路、攻击、倒下）。如果四肢被拉长、身体撕裂、零件飞出去，改关节再跑一次（最多两次）；还不行就在报告里写出来。

## 骨骼命名（名字决定动作）

| 名字 | 是什么 | 父骨骼 |
| --- | --- | --- |
| `body` | 躯干，从腰/臀到胸（两足竖着，四足横着从屁股到胸口） | null |
| `head` | 从脖子到头顶 | body |
| `tail1`、`tail2`… | 尾巴一节一节，沿尾巴中线，2–4 节 | body，后面的接前一节 |
| `leg.L` `leg.R` | 两足的腿（从胯到脚底 z≈0） | null |
| `leg.fl` `leg.fr` `leg.bl` `leg.br` | 四足：前左、前右、后左、后右 | null |
| `arm.L` `arm.R` | 手/前肢（两足才有） | body |
| `ear.L` `ear.R` | 耳朵、角、触角、头冠、头顶叶子（只有一个就只写 `ear.L`） | head |
| `wing.L` `wing.R` | 翅膀（从翅根到翅尖） | body |
| `fin.L` `fin.R`（还可 `fin.bl` `fin.br`） | 鳍 | body |

**左右规则：`.L` / `fl` / `bl` = +x 那一边，`.R` / `fr` / `br` = -x 那一边**（和怪兽自己的左右无关）。没有的部位就不写；最少要有 `body` 和 `head`。身体一团、分不出头的（球形、史莱姆）也写 body 和 head：body 占下半，head 占上半。

## 例子

```json
{"bones": [
  ["body", null, [0, -0.2, 0.12], [0, -0.2, 0.45]],
  ["head", "body", [0, -0.2, 0.45], [0, -0.2, 0.95]],
  ["ear.L", "head", [0.2, -0.18, 0.82], [0.36, -0.18, 0.66]],
  ["ear.R", "head", [-0.2, -0.18, 0.82], [-0.36, -0.18, 0.66]],
  ["arm.L", "body", [0.2, -0.28, 0.4], [0.24, -0.32, 0.22]],
  ["arm.R", "body", [-0.2, -0.28, 0.4], [-0.24, -0.32, 0.22]],
  ["leg.L", null, [0.1, -0.2, 0.15], [0.1, -0.22, 0.0]],
  ["leg.R", null, [-0.1, -0.2, 0.15], [-0.1, -0.22, 0.0]],

  ["tail2", "tail1", [0, 0.15, 0.1], [0.05, 0.3, 0.12]]
]}
```
